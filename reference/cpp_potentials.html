C++ potentials¶

Every potential derives from rgpot::Potential<Derived>, which derives from rgpot::PotentialBase. Energies are eV, lengths are Angstrom and forces are eV/Angstrom unless an entry says otherwise. This page lists the constructors, their configuration structs and the members each class adds. The members every potential inherits (forceImpl, forceBatch, caps, setCache, …) are on C++ API. How the classes fit together is on Architecture.

A force call takes a rgpot::ForceInput: nAtoms, pos (3 * nAtoms doubles, x y z per atom, Angstrom), atmnrs (one atomic number per atom) and box (nine doubles, one cell vector per row, Angstrom). It writes a rgpot::ForceOut: F (3 * nAtoms doubles, same layout as pos, eV/Angstrom), energy (eV), variance, and stress with has_stress. stress is the Cauchy stress in eV/Angstrom3, nine entries row-major. A potential that writes it sets has_stress to 1, and to 0 when the cell volume is not positive.

The program below evaluates a Lennard-Jones dimer with the default parameters. It links against librgpot.

#include <cstdio>

#include "rgpot/LennardJones/LJPot.hpp"

int main() {
  rgpot::LJPot pot({.u0 = 1.0, .cutoff = 15.0, .psi = 1.0});
  const double pos[6] = {0.0, 0.0, 0.0, 1.5, 0.0, 0.0};
  const int z[2] = {18, 18};
  const double box[9] = {40.0, 0.0, 0.0, 0.0, 40.0, 0.0, 0.0, 0.0, 40.0};
  double forces[6] = {};
  rgpot::ForceInput in{2, pos, z, box};
  rgpot::ForceOut out{};
  out.F = forces;
  pot.forceImpl(in, &out);
  std::printf("energy %.6f eV\n", out.energy);
  std::printf("force on atom 1, x: %.6f eV/Angstrom\n", forces[3]);
  return 0;
}

Configuration structs¶

Each struct is a plain aggregate with inline defaults. Construct it with designated initializers and pass it to the constructor of its class.

rgpot::LJConfig¶

Inputs

u0 (well depth, default 1.0), cutoff (truncation distance, default 15.0), psi (zero-crossing distance, default 1.0), switch_width (width of the quintic switch that ends at cutoff, default 0.0, which keeps the shifted truncation).

Units

u0 in eV; cutoff, psi and switch_width in Angstrom.

Outputs

the parameters of rgpot::LJPot.

Errors

the constructor throws std::invalid_argument when switch_width is non-zero and not in (0, cutoff]. No other field is checked.

rgpot::LJClusterConfig¶

Inputs

the fields of rgpot::LJConfig with the same defaults: u0 1.0, cutoff 15.0, psi 1.0, switch_width 0.0.

Units

u0 in eV; cutoff, psi and switch_width in Angstrom.

Outputs

the parameters of rgpot::LJClusterPot.

Errors

the constructor throws std::invalid_argument when switch_width is non-zero and not in (0, cutoff]. A cutoff of 0 or less is accepted and keeps every pair.

rgpot::MorseConfig¶

Inputs

De (well depth, default 0.7102), a (range, default 1.6047), re (equilibrium distance, default 2.8970), cutoff (default 9.5), switch_width (default 0.0). The defaults are the platinum set of the header.

Units

De in eV, a in 1/Angstrom, re, cutoff and switch_width in Angstrom.

Outputs

the parameters of rgpot::MorsePot.

Errors

the constructor throws std::invalid_argument when switch_width is non-zero and not in (0, cutoff]. No other field is checked.

rgpot::ZBLConfig¶

Inputs

cut_inner (where the switch starts, default 2.0), cut_global (truncation distance, default 2.5).

Units

Angstrom.

Outputs

the parameters of rgpot::ZBLPot.

Errors

the constructor throws std::invalid_argument unless 0 < cut_inner < cut_global.

rgpot::SuttonChenConfig¶

Inputs

epsilon (default 1.0), c (default 34.408), a (default 1.0), n (repulsive exponent, default 10), m (density exponent, default 8), cutoff (default 40.0; 0 or less keeps every pair), periodic (minimum image, default false), stress (write the stress, default false). The defaults are the reduced platinum and gold 10-8 potential.

Units

epsilon sets the energy unit and a the length unit; cutoff is in the coordinate unit; c, n and m are dimensionless.

Outputs

the parameters of rgpot::SuttonChenPot.

Errors

the constructor throws std::invalid_argument when n or m is below 1, when a is not positive, when epsilon, c or cutoff is not finite, and when periodic is set with a cutoff that is not positive.

rgpot::EAMCellConfig¶

Inputs

none; the struct has no fields.

Units

none.

Outputs

the argument of rgpot::EAMPot, whose element table is built into the kernel.

Errors

none.

rgpot::EAMTableConfig¶

Inputs

path (the table file, no default), format (EAMTableFormat::Funcfl, Setfl or FinnisSinclair, default Setfl), periodic (minimum image, default true), stress (write the stress, default false), skin (Verlet skin of the potential’s own pair list, default 1.0).

Units

none; the table carries its own units, eV and Angstrom for the LAMMPS metal files. skin is in the length unit of the table.

Outputs

the parameters of rgpot::EAMTablePot.

Errors

the constructor throws std::invalid_argument when path cannot be opened, when the file does not parse as format, and when skin is negative or not finite.

rgpot::EMTConfig¶

Inputs

rasmussen (default false): true selects the Rasmussen parameter provider of Asap, false the Asap default provider.

Units

none.

Outputs

the parameters of rgpot::EMTPot.

Errors

none.

rgpot::WaterConfig¶

Inputs

cutoff (default 8.5), switching_width (default 1.0). The defaults are the values the eOn wrappers pass.

Units

Angstrom.

Outputs

the parameters of rgpot::TIP4PPot, rgpot::SPCEPot and rgpot::TIP4PPtPot.

Errors

none; the constructors do not check the fields.

rgpot::D3Config¶

Inputs

damping (D3Damping::BJ, the rational damping, or D3Damping::Zero; default BJ), functional (the s-dftd3 method key, default "pbe"), atm (the Axilrod-Teller-Muto three-body term, default true).

Units

none.

Outputs

the parameters of rgpot::D3Pot.

Errors

the constructor throws std::invalid_argument for an empty functional, and std::runtime_error when s-dftd3 cannot load damping parameters for it.

rgpot::D4Config¶

Inputs

functional (the dftd4 method key, default "pbe"), charge (total charge, default 0.0), atm (the many-body term, default true).

Units

charge in elementary charges.

Outputs

the parameters of rgpot::D4Pot.

Errors

the constructor throws std::invalid_argument for an empty functional, and std::runtime_error when dftd4 cannot load damping parameters for it. charge is not checked.

rgpot::lr::CoulombConfig¶

Inputs

method (CoulombMethod::Ewald, SPME or DSF, default Ewald), cutoff (real-space or DSF cutoff, default 9.0), alpha (splitting parameter, default 0.30), kmax (Ewald reciprocal shell, default 8), grid (SPME mesh, default 32 32 32), spline_order (SPME B-spline order, default 6), short_cutoff (short list, default 4.0), skin (default 1.0), periodic (default true), stress (default true).

Units

cutoff, short_cutoff and skin in Angstrom; alpha in 1/Angstrom; the others are counts or flags.

Outputs

the parameters of rgpot::lr::CoulombPot. stress false skips the strain and lets the SPME mesh run in single precision.

Errors

the constructor checks no field. The force call throws std::invalid_argument when cutoff or alpha is not positive, when kmax is below 1 with Ewald, and when spline_order is outside 3 to 16 with SPME. SPME raises a grid entry below 4 to 4.

rgpot::lr::DispersionConfig¶

Inputs

kind (DispersionKind::D3BJ, D4, MBD or QDO, default QDO), functional (D3 and D4 method key, default "pbe"), atm (three-body term, default true), charge (D4 total charge, default 0.0), mbd_beta (default 0.83), mbd_a (default 6.0), mbd_k (Monkhorst-Pack mesh for periodic MBD, default 4 4 4), mbd_gamma (one k-point at Gamma instead of the shifted mesh, default false), qdo_scale (default 1.0), qdo_legacy (legacy QDO tables, default false), qdo_damped (default true), cutoff (pair list cutoff, default 15.0), lib_disp2, lib_disp3 and lib_cn (library real-space cutoffs, default 0.0, which keeps the library default), switch_width (default 0.0, a hard cutoff), short_cutoff (default 4.0), skin (default 1.0), periodic (default false).

Units

cutoff, switch_width, short_cutoff and skin in Angstrom; lib_disp2, lib_disp3 and lib_cn in bohr; charge in elementary charges; the others are dimensionless, counts or flags.

Outputs

the parameters of rgpot::lr::DispersionPot.

Errors

the constructor checks no field. Invalid values surface as the errors of the force call listed under rgpot::lr::DispersionPot.

rgpot::lr::NlhConfig¶

Inputs

cutoff (default 2.0), skin (default 0.5), switch_off (distance by which the repulsion is switched off, default 1.5).

Units

Angstrom.

Outputs

the parameters of rgpot::lr::NlhPot.

Errors

the constructor throws std::invalid_argument unless cutoff > switch_off > 0. skin is not checked.

Shared members¶

These members have the same declaration and behaviour on every class listed. A sentence after the fields names a class whose behaviour differs in detail.

.paramsKey¶

[[nodiscard]] uint64_t paramsKey() const noexcept override;
Applies to

rgpot::EAMPot, rgpot::EAMTablePot, rgpot::EMTPot, rgpot::ExprPot, rgpot::LJClusterPot, rgpot::LJPot, rgpot::MorsePot, rgpot::SPCEPot, rgpot::StillingerWeberSi, rgpot::SuttonChenPot, rgpot::TIP4PPot, rgpot::TIP4PPtPot, rgpot::TersoffSiC, rgpot::ZBLPot, rgpot::lr::CoulombPot, rgpot::lr::DispersionPot, rgpot::lr::NlhPot

Inputs

none.

Units

none.

Outputs

a 64-bit FNV-1a hash of the parameters and a kernel version, computed in the constructor. The result cache mixes it into its key.

Errors

none.

rgpot::ExprPot hashes the expression, each term name and each child’s paramsKey. rgpot::lr::CoulombPot does not hash stress or short_cutoff. rgpot::lr::DispersionPot does not hash functional, periodic, switch_width, lib_disp2, lib_disp3, lib_cn, mbd_gamma, qdo_damped, short_cutoff or skin.

.setNeighbourMode¶

.locality¶

[[nodiscard]] Locality locality() const noexcept;
Applies to

rgpot::EAMTablePot, rgpot::LJPot, rgpot::MorsePot, rgpot::SuttonChenPot

Inputs

none.

Units

cutoff in the length unit of the potential: Angstrom for rgpot::LJPot and rgpot::MorsePot, the unit of a for rgpot::SuttonChenPot and the unit of the table for rgpot::EAMTablePot.

Outputs

a rgpot::Locality from CppCore/rgpot/Locality.hpp. cutoff is the range of each site energy, pairwise is true when every energy term is a function of one pair distance, and densities is the number of values per atom that densityStage sums and forceStage reads. forceRange() is cutoff for a pairwise potential and twice cutoff otherwise; the atoms within it of an atom set the force on that atom. .densityStage¶

void densityStage(const HalfList &list, double *densities) const;
Applies to

rgpot::EAMTablePot, rgpot::SuttonChenPot

Inputs

list, a rgpot::HalfList from CppCore/rgpot/Staged.hpp. It holds the positions and atomic numbers of the host’s nOwned atoms followed by their copies, nAtoms in all, and a half neighbour list over the owned atoms in the layout of a LAMMPS NeighList. densities holds locality().densities values per atom for all nAtoms atoms, zeroed by the caller.

.forceStage¶

void forceStage(const HalfList &list, const double *densities, double *forces,
                StageTally *tally) const;
Applies to

rgpot::EAMTablePot, rgpot::LJPot, rgpot::MorsePot, rgpot::SuttonChenPot

Inputs

list as for .densityStage, and densities after the host completed them; the pair potentials do not read densities. forces holds 3 * nAtoms doubles, and tally is a rgpot::StageTally or null.

Units

the units of forceImpl.

Outputs

adds the force of each listed pair to its row atom, and the opposite force to the other atom when that one is owned or list.newton is set. The many-body potentials take the embedding derivative of both atoms of a pair from their densities, so a copy needs the densities of its owner. With a tally it adds the host’s share of the energy and of the virial W = -V sigma, in the order xx, yy, zz, yz, xz, xy. the derivative of the expression with respect to that term, evaluated at the child energies of the last force call. Before any force call the child energies are 0.

Errors

throws std::invalid_argument when name is not a term.

Term names and constructor failures¶

How to compose terms is in Compose potentials with ExprPot.

A term name must be a Lepton identifier: an ASCII letter or underscore first, then ASCII letters, digits, or underscores. lj, morse, and d3 are valid. 1lj, lj-x, and lj.x are not.

The constructor throws std::invalid_argument before any force call when:

  • the expression is empty or blank

  • there are zero terms

  • a name is not a Lepton identifier

  • a name is duplicated

  • a child pointer is null

  • Lepton cannot parse or compile the expression

  • a supplied name is missing from the expression

  • an identifier in the expression has no child

  • ParsedExpression::differentiate(name) fails

Python raises ValueError with the same message.

Long-range summands¶

These classes are in namespace rgpot::lr and are built with -Dwith_long_range=true. Each one owns a DualList, a pair list with a short and a long cutoff, until setNeighbours replaces it.

rgpot::lr::CoulombPot¶

CoulombPot(CoulombConfig cfg, std::shared_ptr<ChargeSource> charges,
           std::shared_ptr<ChargeResponse> response = nullptr);
Inputs

a rgpot::lr::CoulombConfig; charges gives the per-atom charges and the net charge each call; response, when not null, adds the chain rule for charges that depend on positions.

Units

Outputs

the constructor throws std::invalid_argument for a null charges. The force call throws std::invalid_argument in the cases of rgpot::lr::CoulombConfig, when a charge, the net charge or a position is not finite, and when the charges do not sum to the net charge within 1e-6 (1 + |net charge|). FixedCharges throws std::invalid_argument when its length does not match the atom count.

rgpot::lr::DispersionPot¶

explicit DispersionPot(DispersionConfig cfg, std::shared_ptr<RatioSource> ratios = nullptr,
                       std::shared_ptr<RatioResponse> response = nullptr);
Inputs

a rgpot::lr::DispersionConfig; ratios gives the Hirshfeld volume ratio and the C6 ratio per atom, and null uses ratio 1 for every atom; response, when not null, adds the chain rule for ratios that depend on positions, by central differences of the energy.

FixedRatios throws std::invalid_argument when a ratio vector does not match the atom count.

Fortran kernels¶

These classes are in namespace rgpot::fortranpots and are built with -Dwith_fortran_pots=enabled. Each has only a default constructor. Each instance owns a Fortran workspace with its own neighbour table, kept between calls. A kernel failure throws std::runtime_error with the label of the kernel, the status and the kernel’s message. A workspace that cannot be allocated throws std::bad_alloc from the constructor. Zero atoms give zero energy and forces. Energy is eV and forces are eV/Angstrom. The porting rules are on Fortran potentials: porting rules.
