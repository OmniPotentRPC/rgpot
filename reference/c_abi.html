C ABI of rgpot-core¶

rgpot-core/include/rgpot.h declares the C ABI of the Rust crate rgpot-core. The header is generated by cbindgen from rgpot-core/src. It includes dlpack/dlpack.h and uses eindir_objective_t and eindir_abi_stamp_t without declaring them. A C caller includes rgpot/eindir_abi.hpp first, which declares both; a C++ caller includes rgpot/c_api.hpp. The RPC names are declared only when RGPOT_HAS_RPC is defined before the header. The neighbour-list, fast-list and plugin symbols of librgpot have their own pages: Neighbour-list C ABI, Fast neighbour list and Plugin ABI. Why the ABI stamp exists is in ABI stamps, and how to bump it is in Bump the ABI numbers. The reasons for the Hessian-vector design are in Hessian-vector products.

The C ABI converts no units. Positions and cell are in the length unit of the potential behind the callback, energy in its energy unit, and forces in energy per length. The C++ potentials of librgpot use Angstrom and eV.

The examples on this page are compiled against the header and not run: a Meson build exports these functions only when it is configured with with_rust_core.

Errors¶

rgpot_status_t¶

Inputs

none; an enum.

Units

none.

Outputs

RGPOT_SUCCESS (0), RGPOT_INVALID_PARAMETER (1), RGPOT_INTERNAL_ERROR (2), RGPOT_RPC_ERROR (3), RGPOT_BUFFER_SIZE_ERROR (4).

Errors

none. No function of rgpot-core returns RGPOT_BUFFER_SIZE_ERROR itself; a callback may return it and it is passed through.

A function wrapped in the crate’s panic guard returns RGPOT_INTERNAL_ERROR for a caught Rust panic and stores the panic message. The guarded functions are rgpot_potential_calculate, rgpot_potential_hvp, rgpot_potential_hvp_centre, rgpot_rpc_calculate and rgpot_rpc_server_start.

rgpot_last_error¶

const char *rgpot_last_error(void);
Inputs

none.

Units

none.

Outputs

the message of the last failure recorded on the calling thread, NUL-terminated, or the empty string when none was recorded. Do not free it.

Errors

none; the call cannot fail.

The message is thread-local. A failing call replaces it; a successful call leaves the previous message in place, so read it only after a call returned an error. The header states that the pointer is valid until the next rgpot_* call on the same thread. A message that contains a NUL byte is stored as (error message contained interior NUL). When a callback returns an error status, rgpot-core stores no message of its own: the text is whatever the callback stored, or an older message.

#include <stdio.h>

#include "rgpot/eindir_abi.hpp"
#include "rgpot.h"

int report(const rgpot_potential_t *pot, const rgpot_force_input_t *input,
           rgpot_force_out_t *output) {
  rgpot_status_t s = rgpot_potential_calculate(pot, input, output);
  if (s != RGPOT_SUCCESS) {
    fprintf(stderr, "rgpot error %d: %s\n", (int)s, rgpot_last_error());
    return 1;
  }
  return 0;
}

Tensors¶

The tensor functions take and return DLPack DLManagedTensorVersioned pointers. Every tensor they create is on the CPU with device id 0, row-major strides and DLPack version 1.0. The borrowing constructors do not check their arguments; rgpot_tensor_owned_cpu_f64_2d and the accessors handle NULL as their entries say.

rgpot_tensor_cpu_f64_2d¶

DLManagedTensorVersioned *rgpot_tensor_cpu_f64_2d(double *data, int64_t rows, int64_t cols);
Inputs

data points to rows * cols doubles that stay alive while the tensor lives; rows and cols are the shape.

Units

those of data.

Outputs

a new tensor of shape [rows, cols], dtype float64, that borrows data. Free it with rgpot_tensor_free, which frees the metadata and not data.

Errors

none checked; the pointer and the shape are stored as given.

those of data.

rgpot_tensor_owned_cpu_f64_2d¶

DLManagedTensorVersioned *rgpot_tensor_owned_cpu_f64_2d(const double *data,

Force input and output¶

rgpot_force_input_t¶

Inputs

three borrowed tensor pointers: positions ([n_atoms, 3], float64), atomic_numbers ([n_atoms], int32) and box_matrix ([3, 3], float64, lattice vectors as rows). The caller keeps the tensors and their data alive while the struct is used.

Units

positions and cell in the length unit of the potential; atomic numbers have none.

Outputs

none; a struct. n_atoms is read from shape[0] of positions.

Errors

none; the functions that read it state their checks.

rgpot_force_out_t¶

Inputs

none; a struct that a potential callback fills.

Units

energy in the energy unit of the potential and forces in energy per length; variance is passed through as the potential reports it.

Outputs

forces (a tensor [n_atoms, 3], float64, set by the callee; the caller owns it and frees it with rgpot_tensor_free), energy, and variance (0 when the potential gives no uncertainty).

Errors

none.

rgpot_force_input_create¶

struct rgpot_force_input_t rgpot_force_input_create(uintptr_t n_atoms,

                                                    int *atmnrs,

n_atoms; pos with 3 * n_atoms doubles in row-major order; atmnrs with n_atoms int values; box_ with 9 doubles, lattice vectors as rows. All arrays stay alive while the struct is used.

Units

positions and cell in the length unit of the potential.

Outputs

a struct of three new tensors that borrow the arrays. Release them with rgpot_force_input_free.

Errors

none checked; the pointers are wrapped as given.

Potential handles¶

PotentialCallback¶

typedef enum rgpot_status_t (*PotentialCallback)(void *user_data,
                                                 const struct rgpot_force_input_t *input,
                                                 struct rgpot_force_out_t *output);
Inputs

user_data given to the constructor; input the geometry; output storage whose forces is NULL.

Units

those of the potential.

Outputs

the callback sets output->forces to a tensor with a deleter, and output->energy and output->variance; it returns RGPOT_SUCCESS or an error status.

Errors

rgpot_potential_calculate returns the callback’s status unchanged and does not check its output. The Hessian-vector entry points and the eindir evaluation path check the output: forces must be a float64 CPU tensor of 3 * n_atoms finite elements, one- or two-dimensional, C-contiguous and aligned, and energy must be finite; otherwise the call fails with RGPOT_INVALID_PARAMETER (EINDIR_INVALID_PARAMETER on the eindir path).

The function pointer is not nullable: a NULL callback passed to a constructor is undefined behaviour.

rgpot_potential_t¶

Inputs

none; a struct created by rgpot_potential_new or rgpot_potential_new_eindir.

Units

Outputs

Hessian-vector products¶

RGPOT_HVP_DEFAULT_STEP is 1.0e-3, the step used when a caller passes 0. The centre cache keys on the bits of the positions, the atomic numbers and the cell, so -0.0 and 0.0 are different centres. A NULL atomic_numbers or box_matrix tensor is allowed and is part of the key as absent. The cache holds one centre per handle and is guarded by a mutex; when two threads store centres, the later one stays.

rgpot_hvp_scheme_t¶

Inputs

none; an enum passed as int32_t.

Units

none.

Outputs

RGPOT_HVP_AUTO (0): the analytic callback when one is registered, else forward. RGPOT_HVP_FORWARD (1): (F(x) - F(x + h u)) |v| / h with u = v / |v|, F(x) from the cached centre. RGPOT_HVP_CENTRAL (2): (F(x - h u) - F(x + h u)) |v| / (2 h), two force calls. RGPOT_HVP_ANALYTIC (3): the registered callback.

Errors

none; rgpot_potential_hvp refuses any other value.

rgpot_potential_hvp¶

enum rgpot_status_t rgpot_potential_hvp(const struct rgpot_potential_t *pot,
                                        const struct rgpot_force_input_t *input,
                                        const double *direction,
                                        double step,
                                        int32_t scheme,
                                        double *hv_out);
Inputs

pot a live handle; input the geometry; direction with 3 * n_atoms finite doubles laid out like the positions; step the displacement h along direction / |direction|, 0 for RGPOT_HVP_DEFAULT_STEP; scheme a rgpot_hvp_scheme_t value; hv_out with room for 3 * n_atoms doubles, not overlapping direction.

Units

step in the length unit of the positions; hv_out in energy per length squared times the unit of direction.

Outputs

hv_out holds H direction, 3 * n_atoms doubles laid out like the positions. A zero direction writes zeros and makes no call. The finite differences write hv_out only on success; a failing analytic callback may leave it partly written.

Errors

RGPOT_INVALID_PARAMETER, with a message naming the problem, for: a NULL pot, input, direction or hv_out; a scheme outside 0 to 3; a NULL positions tensor or one without a shape; overlapping direction and hv_out; a refused peer; a positions tensor that is not a CPU float64 C-contiguous tensor of 3 * n_atoms finite elements; a non-null atomic_numbers that is not int32 with n_atoms elements, or a non-null box_matrix that is not float64 with 9 elements; a non-finite direction element; a negative or non-finite step; RGPOT_HVP_ANALYTIC with no callback registered; a force callback output that fails the checks of PotentialCallback; a non-finite analytic output. A force or analytic callback’s error status is returned unchanged, and rgpot-core stores no message for it. RGPOT_INTERNAL_ERROR for a caught panic.

#include "rgpot/eindir_abi.hpp"
#include "rgpot.h"

/* k forward products at one centre: k + 1 force calls. */
rgpot_status_t products(const rgpot_potential_t *pot,
                        const rgpot_force_input_t *input, int k,
                        const double *const *q, double *hq) {
  rgpot_force_out_t centre = rgpot_force_out_create();
  rgpot_status_t s = rgpot_potential_hvp_centre(pot, input, &centre);
  if (s != RGPOT_SUCCESS) {
    return s;
  }
  rgpot_tensor_free(centre.forces);
  for (int i = 0; i < k && s == RGPOT_SUCCESS; ++i) {
    s = rgpot_potential_hvp(pot, input, q[i], 0.0, RGPOT_HVP_FORWARD, hq);
  }
  return s;
}

#include <stdio.h>
#include <stdlib.h>

#include "rgpot/eindir_abi.hpp"
#include "rgpot.h"

int main(void) {
  rgpot_abi_stamp_t built = {RGPOT_ABI_VERSION_MAJOR, RGPOT_ABI_VERSION_MINOR,
                             RGPOT_ABI_LAYOUT_REVISION};
  if (!rgpot_abi_compatible(&built)) {
    rgpot_abi_stamp_t have = rgpot_abi_stamp();
    fprintf(stderr, "librgpot ABI %u.%u layout %u, built against %u.%u layout %u\n",
            have.abi_major, have.abi_minor, have.layout_revision,
            built.abi_major, built.abi_minor, built.layout_revision);
    abort();
  }
  return 0;
}
