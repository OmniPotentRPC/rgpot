Engine plugin ABI¶

CppCore/rgpot/engine_c_abi.h declares the functions a host calls to drive an engine shared library through dlopen and dlsym. The host selects the backend by the library it opens. The configuration is a Cap’n Proto flat-array message whose root is the engine’s params struct in Potentials.capnp. Positions and cells are in Angstrom, energies in eV and forces in eV/Angstrom. A cell is nine doubles in row-major order.

Status codes are three-valued. 0 is success. A positive value means the evaluation failed at this input and the caller may back off. A negative value means the instance is unusable. The engines in this repository return 1 for an invalid argument, 2 when the evaluation or the setting failed (the reason is in rgpot_engine_last_error), and 3 when the backend does not support the operation. rgpot_engine_force and rgpot_engine_force_batch also return the nonzero code of the host’s coordinate transform.

To open, build and test an engine, see Open, build and test engine plugins.

Libraries¶

CppCore/rgpot/engine/EngineTable.cc implements every function the engine libraries export, for any PotentialBase. Each library adds one file that defines rgpot::engine::create (build the potential from the params message) and rgpot::engine::backend_name.

BuiltinParams.name is compared in lower case. The Metatomic and XTB libraries also export their own tables (rgpot_mta_*, rgpot_xtb_*). NWChem and CPMD keep the prefix-parameterized profile ABI that NWChemPot and CPMDPot load, and MOPAC keeps mopac_c_abi.h. The plugin interface in include/rgpot/plugin.h is a separate family. tblite, dftd3, dftd4, ExprPot, XcKernel, CPMD and CP2K have no engine library.

Every library above exports rgpot_engine_force_batch, rgpot_engine_abi_stamp, rgpot_engine_abi_compatible, rgpot_engine_name, rgpot_engine_version, rgpot_engine_model_digest, rgpot_engine_caps, rgpot_engine_last_error, rgpot_engine_set_num_threads and rgpot_engine_set_charge_spin. None of them exports rgpot_engine_model_state, rgpot_engine_set_callbacks, rgpot_engine_hint or rgpot_engine_neighbor_options.

Errors

RgpotEngineAbiStamp¶

Inputs

none; a value type.

Units

none.

Outputs

three unsigned short fields: abi_major (RGPOT_ENGINE_ABI_VERSION, 1), abi_minor (RGPOT_ENGINE_ABI_MINOR, 2) and layout_revision (RGPOT_ENGINE_ABI_LAYOUT_REVISION, 1).

Errors

none.

The major increments for an incompatible change. The minor increments for an addition that leaves every existing call valid: a new optional symbol, or a new field at the end of a size-prefixed structure. The layout revision increments when an existing structure changes size or field order. A host built against minor N runs against an engine of the same major and layout revision whose minor is at least N. An engine without rgpot_engine_abi_stamp is minor 0, layout 1. Minor 1 added the stamp, rgpot_engine_caps, rgpot_engine_last_error, rgpot_engine_set_num_threads and rgpot_engine_set_charge_spin. Minor 2 added rgpot_engine_name, rgpot_engine_version, rgpot_engine_model_digest and the generic table for every backend. The version does not cover the Cap’n Proto params schema, the tensor runtime the engine links, or the model.

Instances¶

RgpotEnginePot¶

Inputs

none; an opaque handle.

Units

none.

Outputs

returned by rgpot_engine_create and released by rgpot_engine_destroy.

Errors

none.

A handle holds the backend potential, its capabilities, the last error message and the model digest once computed.

rgpot_engine_create¶

RgpotEnginePot *rgpot_engine_create(const void *config, size_t config_len,
                                    char *errbuf, size_t errlen);
Inputs

config, a Cap’n Proto flat-array message (as produced by capnp::messageToFlatArray) whose root is the library’s params struct; config_len, its length in bytes; errbuf and errlen, a buffer for the failure reason (may be null or 0).

Units

none.

Outputs

a new handle, or NULL on failure.

Errors

returns NULL and writes the reason to errbuf (at most errlen - 1 bytes, NUL-terminated). A null config, a zero config_len or a length that is not a multiple of 8 gives rgpot_engine_create(<name>): a word-aligned Cap'n Proto params message is required. An empty modelPath (UMA, Metatomic), an unknown BuiltinParams.name, a malformed message or an exception from the backend constructor gives that message. A MetatomicParams.charge or spin the model does not read, other than charge 0 or multiplicity 1, gives rgpot_engine_create(metatomic): followed by the reason rgpot_engine_set_charge_spin gives.

Required symbol. UmaParams and MetatomicParams carry intraopThreads and interopThreads (default 1), which create applies with the rules of rgpot_engine_set_num_threads; a refused inter-op count fails create with the reason. UmaParams.deterministicAlgorithms turns on deterministic torch algorithms, so an operation without a deterministic implementation throws. MetatomicParams.torchDeterminism (fast or deterministic) selects the TorchDeterminismPolicy of the Metatomic potential. MetatomicParams.charge, spin (a value below 1 becomes 1) and attachSystemExtras go to the Metatomic potential; see Charge and spin below. UmaParams.cacheDir is the root of the cache the UMA package is unpacked into; see the UMA unpack cache below.

rgpot_engine_destroy¶

void rgpot_engine_destroy(RgpotEnginePot *pot);
Inputs

pot, a handle from rgpot_engine_create or NULL.

Units

none.

Outputs

none; the handle and its backend are freed.

Errors

none; NULL is accepted.

Required symbol. Must not run concurrently with another call on the same handle.

RgpotEngineCaps¶

Inputs

size, set by the host to sizeof(RgpotEngineCaps) before rgpot_engine_caps.

Units

none.

Outputs

size (bytes the engine wrote), reentrancy, per_image_instances, batched, periodic, stress and group_collective; the flags are 0 or 1.

Errors

none.

The fields mirror rgpot’s PotCaps. per_image_instances asks multi-image methods (NEB) to clone one instance per image. batched means the backend serves rgpot_engine_force_batch natively. periodic means periodic boundary conditions are supported. stress means the backend computes cell stress; the engine ABI has no call that returns it. group_collective means every rank of a calculator group enters each call.

reentrancy decides how the table admits concurrent rgpot_engine_force and rgpot_engine_force_batch calls:

  • 0, shared instance: calls run concurrently on one handle (UMA, Metatomic).

  • 1, per instance: one call at a time per handle; calls on different handles run concurrently (XTB and every potential of the classical engine).

  • 2, process serial: one call at a time across all handles of the library in the process (MOPAC, NWChem, Skala).

rgpot_engine_caps¶

int rgpot_engine_caps(const RgpotEnginePot *pot, RgpotEngineCaps *out);
Inputs

pot, a handle; out, a structure whose size field the host has set.

Units

none.

Outputs

0 on success; the engine copies at most out->size bytes of its structure into out and sets out->size to the number of bytes written.

Errors

returns 1 when pot or out is null, or when out->size is smaller than an unsigned; out is then not written and rgpot_engine_last_error is not set.

Optional symbol.

rgpot_engine_last_error¶

size_t rgpot_engine_last_error(const RgpotEnginePot *pot, char *buf, size_t len);
Inputs

pot, a handle; buf and len, the destination (may be null or 0 to query the length).

Units

none.

Outputs

the full length of the message of the last failed call on the handle, 0 when there is none; at most len - 1 bytes are copied to buf and NUL-terminated.

Errors

a null pot returns 0 and writes nothing.

Optional symbol. Reading does not clear the message. A successful rgpot_engine_force, rgpot_engine_force_batch, rgpot_engine_set_num_threads or rgpot_engine_set_charge_spin clears it. Errors of rgpot_engine_create go to its errbuf. May run at any time, also during an evaluation on the same handle.

rgpot_engine_model_digest¶

size_t rgpot_engine_model_digest(const RgpotEnginePot *pot, char *buf, size_t len);
Inputs

pot, a handle; buf and len, the destination.

Units

none.

Outputs

64, with the SHA-256 of the model file as 64 lowercase hexadecimal digits copied to buf (at most len - 1 bytes, NUL-terminated); 0 when the backend has no model file.

Errors

returns 0 and writes an empty string when pot is null, the backend has no model file (every library except UMA and Metatomic), or the file cannot be read.

Optional symbol. The digest is computed on the first request and kept for the life of the handle, including a failed read. For libuma_engine it is the digest of the .pt2; the digest of the weights inside it is package metadata, under UMA checkpoint provenance below. May run at any time.

rgpot_engine_set_num_threads¶

int rgpot_engine_set_num_threads(RgpotEnginePot *pot, int intra_op, int inter_op);
Inputs

pot, a handle; intra_op and inter_op, the intra-op and inter-op worker thread counts of the engine’s tensor runtime (a value below 1 leaves that count alone).

Units

none.

Outputs

0 on success.

Errors

returns 1 for a null pot (no message). Returns 3 for a backend without a tensor runtime (every library except UMA and Metatomic), with backend has no tensor runtime in rgpot_engine_last_error. Returns 2 when the runtime refuses the setting, with the reason in rgpot_engine_last_error.

Optional symbol. The counts act on the process’s libtorch, so engines in one process share them. The inter-op count can be set once per process before the runtime starts parallel work; asking for the count already in force succeeds and another count afterwards returns 2. Must not run concurrently with another call on the same handle.

Charge and spin¶

rgpot_engine_set_charge_spin sets the total charge and the spin multiplicity of the next calls on a handle, and a multiplicity below 1 returns 1. A value the backend cannot take returns 3, keeps the values in force and leaves the reason in rgpot_engine_last_error. No engine returns 0 for a value its model does not receive.

library

charge and multiplicity

libuma_engine

graph inputs of every call; UmaParams.charge and spin at create

libmetatomic_engine

system data the model declares; MetatomicParams.charge and spin at create

libskala_engine

the NWChem input of the next call; NWChemParams.charge and multiplicity at create

libclassical_engine, libmopac_engine, libnwchem_engine, libxtb_engine

none, so 3 for any value

A UMA package records the charge and spin it was exported for, and the next force call reports a mismatch. A Metatomic model reads the charge as rgpot::charge and the multiplicity as rgpot::spin_multiplicity or rgpot::spin. Each system carries the names the model declares in requested_inputs. Without attachSystemExtras, a model that declares none of them gets 3 from rgpot_engine_set_charge_spin. A value the model does not read must stay at its default, charge 0 or multiplicity 1. rgpot_engine_set_charge_spin returns 3 for another, and create fails for one in MetatomicParams. MetatomicParams.attachSystemExtras attaches all three names and accepts any value, for a model that reads them without declaring them. It needs checkConsistency off, because metatomic then rejects data the model does not declare. Metatomic and the engine ABI shows the declaration.

UMA unpack cache¶

UmaParams.cacheDir (UmaConfig::cache_dir for a directly compiled UmaPot) names the root of the persistent cache that the .pt2 is unpacked into. When it is empty the root is $RGPOT_CACHE_DIR, then $XDG_CACHE_HOME/rgpot (absolute values only), then .rgpot-cache in the working directory. torch’s AOTIModelPackageLoader is not used, because it unpacks into a new directory under the system temporary directory and leaves it behind when the process dies.

Path under the root

Contents

aoti/<sha256>.model/

the package’s data/aotinductor/model files and constants, as torch lays them out

aoti/<sha256>.model/rgpot-unpack.manifest

package digest, model name, and the size of every unpacked file

aoti/.<sha256>.model.tmp-*

an unpack in progress

<sha256> is the digest of the .pt2 bytes, so two models never share a directory and a rewritten package gets a new one. An unpack is written into a private .tmp- sibling and renamed into place once its manifest is complete. Processes and threads that load the same package at once each build a sibling, one rename wins, and the others use the winner’s directory. A directory whose manifest is missing or whose files have the wrong size is replaced. Shared libraries lose the executable-stack flag (PT_GNU_STACK PF_X) on the way, for loaders that refuse an executable stack. A .tmp- sibling older than an hour, left by a process that died, is removed the next time that package is loaded.

rgpot_engine_model_digest of libuma_engine is the SHA-256 of the .pt2. The digest of the weights inside it is package metadata, written by scripts/export_uma_aoti.py:

CP2K shim¶

CP2KPot drives CP2K through libcp2kc_rgpot, a shim over libcp2k declared in CppCore/rgpot/CP2KPot/cp2kc_abi.h (CP2KC_ABI_VERSION 1). This is a separate ABI from the engine table. The shim is the only target that links libcp2k and MPI; CP2KPot opens it with dlopen, so librgpot gains neither dependency. Meson builds it with -Dwith_cp2k=enabled from the libcp2k pkg-config module (CMake: -DRGPOT_WITH_CP2K=ON). Without it librgpot contains no CP2K code, potserv CP2K exits with an error naming the option, and the other potserv backends refuse the cp2k arm in configure(). CP2KPot tries CP2KParams.enginePath, then CP2KC_LIBRARY, then RGPOT_CP2K_ENGINE, then libcp2kc_rgpot.so and ./libcp2kc_rgpot.so (.dylib on macOS).

symbol

purpose

cp2kc_abi_version, cp2kc_version, cp2kc_available

identity

cp2kc_adopt_calculator_comm

borrow the calculator’s MPI_Comm

cp2kc_session_create

write the deck to dir/input.inp, initialise libcp2k once

cp2kc_session_select_orbitals

name the key whose force environment the next call uses

cp2kc_session_calculate

positions and cell in Bohr in, Hartree and Hartree/Bohr forces out

cp2kc_session_destroy

destroy the session’s force environments

The shim uses CP2K’s atomic units and takes no Cap’n Proto. CP2KPot renders the deck from CP2KParams and the first geometry, multiplies positions and cell rows by ANGSTROM_TO_BOHR, and returns the energy times HARTREE_TO_EV and the forces times HARTREE_BOHR_TO_EV_ANGSTROM. libcp2k returns forces, so there is no sign change. The cell rows are the cell vectors a, b and c.

cp2kc_session_calculate returns 0 on success, 1 for a bad argument (including an atom count that differs from the deck), 2 when the SCF did not converge, and a negative value on a fatal error. The rendered deck sets IGNORE_CONVERGENCE_FAILURE, so CP2K warns instead of calling MPI_ABORT. After each evaluation the first rank of the calculator reads the new part of cp2k.out for SCF run NOT converged and shares the result, so every rank returns 2 for the same call. CP2KPot turns code 2 into rgpot::CP2KScfError (a std::runtime_error) on every rank without the error exchange. Any other failure takes the abort path described in MPI. CP2KPot sets has_stress to 0.

XTB table¶

CppCore/rgpot/XTBPot/xtb_c_abi.h declares the table that libxtb_engine exports next to the engine table and that XTBDlopen loads; see C++ engine-backed potentials. CppCore/rgpot/XTBPot/XTBEngineAbi.cc implements it over a linked XTBPot, so Meson builds the library only with -Dwith_xtb=true. Positions and cells are in Angstrom, energies in eV and forces in eV/Angstrom. A cell is nine doubles in row-major order. RGPOT_XTB_ABI_VERSION is 1. The return codes of rgpot_xtb_force are not those of the engine table.

XTBDlopen needs every function below. It refuses a libxtb_engine built before rgpot_xtb_set_warm_min_gap and rgpot_xtb_warm_min_gap existed as missing the C ABI, although that library reports the same version.
