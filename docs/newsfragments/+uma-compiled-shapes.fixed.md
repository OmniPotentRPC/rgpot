UmaPot loads an AOTInductor package exported with fixed shapes that records no `nedges_min`, `nedges_max` or other shape key. The atom and edge counts come from the input checks in the package's wrapper source, which is the shape the graph was compiled for. A system with another atom count or neighbour-list length throws `UmaShapeError` naming that shape. Recorded keys still win, so dynamic packages are unchanged.
