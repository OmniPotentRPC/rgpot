`CoulombPot` gives bit-identical energies, forces and stress at every thread count for DSF, Ewald and SPME. Real space accumulates one partial per fixed chunk, sized from the pair and atom counts, and folds the partials in chunk order. The Ewald wave sum keeps one energy and strain partial per fixed chunk of waves and sums each atom's force over the waves in wave order. The SPME charge spread gives each thread a slab of grid planes and every thread walks the atoms in the same order, so a grid point sums its atoms in one order on any team. The transforms cut each axis into fixed slabs, and the stress kernel keeps one partial per mesh plane. Real space now lands in its own buffer on every path, so running it beside the mesh no longer changes the sum order. An SPME call with `setThreadCount(2)` or `setThreadCount(8)` on a short mesh no longer deadlocks: every rank of the mesh group now counts the group size instead of the caller's thread-local binding. Each `CoulombPot` now owns its screen cache, wave tables, mesh grids and reduction rows, so two instances evaluating on different threads no longer share scratch state.
