`CoulombPot` gives bit-identical energies, forces and stress at every thread count for DSF, Ewald and SPME. Real space and the Ewald wave sum accumulate one partial per fixed chunk, sized from the pair or wave count, and fold the partials in chunk order. The SPME charge spread deposits into fixed z slabs that every plane folds in slab order, the transforms cut each axis into fixed slabs, and the stress kernel keeps one partial per mesh plane. Real space now lands in its own buffer on every path, so running it beside the mesh no longer changes the sum order. An SPME call with `setThreadCount(2)` or `setThreadCount(8)` on a short mesh no longer deadlocks: every rank of the mesh group now counts the group size instead of the caller's thread-local binding.
