`TersoffSiC::setHeldSkin` keeps a skinned neighbour list across `forceImpl` calls. The list is rebuilt when any atom has moved by more than half the skin since the last build, or when the cell or the atom count changes. The skin is 0 by default, which rebuilds on every call as before. `TersoffPot::setHeldSkin` passes the skin to the 1989 kernel; all-silicon calls stay on the Fortran gather. With a positive skin the instance reports `Reentrancy::PerInstance`.
