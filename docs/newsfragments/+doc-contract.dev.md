`docs/doccheck.py` checks the documentation against the source. It requires a reference entry with Inputs, Units, Outputs and Errors for every public C, C++ and Python name, and a classification for every code block in the README and the docs. It runs, compiles or statically checks each block according to that classification, and flags option names, paths and `RGPOT_*` names that do not exist. `pixi r -e docs doccheck` runs it, and the docs CI job runs it with the Sphinx build, which now uses `-W --keep-going`. It replaces `docs/check_c_symbols.py`.
