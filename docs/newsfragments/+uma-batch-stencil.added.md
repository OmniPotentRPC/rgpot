UmaPot evaluates a same-composition stencil in chunks of the package `batch_max` (one compiled forward per chunk, a short chunk padded by repeating its last system) and keeps the per-system loop when `batch_max` is 0 or 1. `scripts/export_uma_aoti.py --batch-max N --molecular-box L` traces that band. The force gradient is traced on torch builds that gate `torch.autograd.grad`, and `OMP_NUM_THREADS` is applied to torch before the compile because the CPU GEMM kernel is built for that thread count.
