UmaPot evaluates a same-composition stencil in chunks of the package `batch_max` and keeps the per-system loop when `batch_max` is 0 or 1. A static band (`--batch-style static`) is traced at exactly `batch_max` systems, and a short chunk repeats its last system. `--batch-style packed` is one disjoint graph with a dynamic atom count and a dynamic edge count (`batch_packed`); UmaPot sends the real system count and does not repeat a system. `scripts/export_uma_aoti.py --batch-max N --molecular-box L` traces either graph. The force gradient is traced on torch builds that gate `torch.autograd.grad`, and `OMP_NUM_THREADS` is applied to torch before the compile because the CPU GEMM kernel is built for that thread count.
