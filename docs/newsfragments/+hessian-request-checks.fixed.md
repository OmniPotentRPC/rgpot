`rgpot_potential_hessian` refuses a Cartesian dimension above 8192 with `RGPOT_INVALID_PARAMETER` instead of reserving the quadratic matrix. Replacing a Hessian or Hessian-vector callback, or invalidating the cache, drops an in-flight matrix so a later request cannot be served the previous curvature. `RGPOT_HVP_ANALYTIC` multiplies a registered dense Hessian when no product callback is registered, and still refuses when neither exact source exists.
