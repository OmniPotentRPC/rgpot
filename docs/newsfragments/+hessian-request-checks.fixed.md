`rgpot_potential_hessian` refuses a dense matrix whose byte count does not fit in `size_t`, or that exceeds a byte budget the caller installed with `rgpot_potential_set_hessian_byte_budget`. There is no built-in dimension or MiB limit. A NULL budget pointer clears the limit. Replacing a Hessian or Hessian-vector callback, or invalidating the cache, drops an in-flight matrix so a later request cannot be served the previous curvature. `RGPOT_HVP_ANALYTIC` multiplies a registered dense Hessian when no product callback is registered, and still refuses when neither exact source exists. A zero-atom request with neither exact source returns `RGPOT_NO_HESSIAN`.
