`ZBLPot` now evaluates orthogonal, sheared and rotated periodic cells through the shared neighbour layer (`caps().periodic` is `true`). Any non-zero cell is treated as periodic, a malformed non-zero cell throws `std::invalid_argument`, and a null or all-zero cell stays open with free boundaries. The ZBL kernel version moves from 1 to 2, so cached ZBL results from earlier versions are invalidated. `ZBLPot` also declares pairwise `locality()`, provides `densityStage` and `forceStage` hooks so `pair_style rgpot` can domain-decompose `ZBL` across ranks, and registers `ZBL` in `rgpot::spec::build`.
