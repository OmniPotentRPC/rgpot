nlist::build lists every periodic image of a pair inside the cutoff on a sheared cell or one narrower than twice the cutoff, with the shift of each image, and the table matches a brute-force sum over images. The pair kernels still sum the nearest image of each pair, which is every image inside the cutoff only while the cutoff is at most half the smallest perpendicular face height; a narrower cell needs nlist::build. A stored list on a sheared cell is rebuilt when an atom changes image, since its shifts are fixed. The C++ soversion is 9, because Neighbours stores the shifts of a list that vesin built. The C++ build links vesin into the neighbour library.
