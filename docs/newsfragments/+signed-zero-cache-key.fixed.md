An eindir gradient is served from the fused energy result only when the positions have the same bits as the energy call. Before, a gradient at `-0.0` was served the result computed at `+0.0`, because the two compare equal. The pair list cache and the half-shell neighbour list now compare the box bit for bit as well, so a box that differs only in the sign of a zero gets its own build. Inputs without a signed zero take the same path as before.
