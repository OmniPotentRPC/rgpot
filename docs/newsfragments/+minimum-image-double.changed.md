The general-cell minimum image is computed in double. An ill-conditioned cell is Minkowski-reduced (Nguyen and Stehlé, ACM Trans. Algorithms 5, 46 (2009), doi:10.1145/1597036.1597050). A reduced basis that is still too ill-conditioned searches the 27 images with coefficients in {-1, 0, 1}. Each product-sum is an explicit fused multiply-add, and that file is compiled with contraction off, so the folded bits do not depend on the instruction set.
