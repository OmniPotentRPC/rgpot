The golden regeneration scripts read the hosts they may run on from `RGPOT_REGEN_HOSTS`, a comma-separated list of host names that is empty by default. Until it lists the current host, `scripts/regen_dftd_goldens.py`, `scripts/regen_expr_goldens.py` and `scripts/regen_xckernel_goldens.py` refuse to run. `DFTD_ALLOW_REGEN=1`, `EXPR_ALLOW_REGEN=1` and `XCKERNEL_ALLOW_REGEN=1` still override the check.
