The regeneration, comparison and timing scripts read the hosts they may run on from `RGPOT_REGEN_HOSTS`, a comma-separated list of host names that is empty by default. Until it lists the current host, `scripts/regen_dftd_goldens.py`, `scripts/regen_expr_goldens.py`, `scripts/regen_xckernel_goldens.py`, `scripts/gen_libxckernel.sh`, `scripts/compare_xckernel_tda_nwchemc.py` and `scripts/time_lj_rgpot_vs_pyeonclient.py` refuse to run. `DFTD_ALLOW_REGEN=1`, `EXPR_ALLOW_REGEN=1`, `XCKERNEL_ALLOW_REGEN=1` and `TIME_LJ_ALLOW=1` still override the check.
