A static MinGW build with the fast pair list builds. It installs `librgpot_fastnlist.a` beside `librgpot.a` and lists it in `rgpot.pc`; before, `ar` took the Rust archive for the archive it was writing. `NeighbourListTest` sets `OMP_NUM_THREADS` with `_putenv_s` on every Windows toolchain, not only MSVC. `print_cxx_layout_stamp` declares fmt, so `CxxSoversion` has its printer when fmt is not on the default include path. `PluginLifetimeTest` and `CxxSoversion` run their program under the cross file's `exe_wrapper`. The `abi_symbols` test is a Python script and needs no POSIX shell, `dumpbin` or `objdump`.
