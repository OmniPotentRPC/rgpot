The engine drivers build on Windows. `lj_eval.cpp` and the engine tests load engine libraries through the cross-platform loader in `rgpot/plugin/DynLib.hpp` instead of `dlfcn.h`. `capi_threads` uses Win32 threads on Windows. On Windows the engines link the static objects librgpot is made of, because the DLL exports only its version. The native Lennard-Jones engine exports `rgpot_md_native_force`, which a Windows DLL did not. The `abi_symbols` tests and the ThreadSanitizer binary are skipped on Windows. The `lj_eval` library declares the fmt headers `LJPot.hpp` includes, so the engines build when fmt is not on the default include path.
