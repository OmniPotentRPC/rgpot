Targets without a hardware fused multiply-add no longer call the libm software implementation of that operation. An inlined Veltkamp/Dekker emulation produces the same bits, vectorized under SSE2 and SSE4. On x86-64 those targets issue the processor's FMA when glibc reports it usable. The general product-sum repairs a half-ulp tie. The exp polynomial and a squared distance use the rounded sum of the same chain.
