LJ, Morse, the analytical EAM kernel, and the orthorhombic fold select an instruction set at run time through Google Highway. `RGPOT_SIMD` names the target and `rgpot::simd::chosen_target_name()` reports it. A product-sum uses a hardware fused multiply-add only on a target the runtime check selected, and only when that target has the instruction. SSE2 and SSE4 use it when glibc reports a usable FMA, and a Dekker product otherwise. LJ and Morse still take their pairs from the pair-list cache.
