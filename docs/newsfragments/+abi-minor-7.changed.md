The C ABI minor of `rgpot-core` is now 7, in `RGPOT_ABI_VERSION_MINOR`, for the additive dense-Hessian exports `rgpot_potential_set_hessian_callback`, `rgpot_potential_set_hessian_byte_budget`, `rgpot_potential_hessian`, `rgpot_potential_hessian_counts` and `rgpot_potential_reset_hessian_counts`, and for the status `RGPOT_NO_HESSIAN`. A caller built against minor 0 to 6 still matches; a caller built against minor 7 is refused by an older library.
