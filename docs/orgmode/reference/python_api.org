* Python API

The extension module is =rgpot._core=.
Stubs live in =rgpot/_core.pyi= and the package ships =py.typed=.
Wrong dtype or order on a float64 argument raises =TypeError=.
A wrong shape raises =ValueError= naming the argument and both shapes.
A non-finite energy raises =rgpot.NumericalError=.

** Calculators

| Symbol                  | Role                                      |
|-------------------------+-------------------------------------------|
| =rgpot.ase.RgpotCalculator= | In-process ASE calculator            |
| =rgpot.ase.RgpotRpcCalculator= | Cap'n Proto ASE calculator      |
| =rgpot.ase.AnnealRunner= | Portfolio relaxation, not an ASE optimizer |
| =rgpot.ase.AnnealOptimizer= | Deprecated alias of =AnnealRunner=   |

=RgpotCalculator.calculate_many(frames)= returns one dict per frame.
=threads= selects the worker count; 0 uses the hardware concurrency.
Results for energy and forces match one call per frame, bit for bit.
The worker count is not part of the result.

See the [[file:../howto/ase.org][ASE how-to]] and the
[[file:../explanation/thread-safety.org][thread-safety]] page.

** Engine constructors

=rgpot.rgpot_lammps_potential=, =rgpot.rgpot_gromacs_potential= and
=rgpot.rgpot_openmm_potential= return a shifted 12-6 potential.
Positions are Angstrom and the energy is eV.
The LAMMPS constructor dlopens the engine plugin.
GROMACS and OpenMM store kJ/mol and nanometres once; =native_u0=,
=native_cutoff= and =native_psi= read those stored values.
The dimer at 1.5 Angstrom with =u0= 1, cutoff 8 and =psi= 1 is
-0.3203213355 eV.

** XcKernel

=XcKernel.contract= takes =chi=, an optional =dchi= (default =None=), and a
required =scal= dict.
The stub writes =scal= as =None= so =dchi= can be omitted.
Passing =None= for =scal= raises =TypeError=.
=k.contract(chi, None, scal)= and =k.contract(chi, scal=scal)= both leave =dchi=
null.
=lapl_chi= and =hess_chi= default to =None=.
