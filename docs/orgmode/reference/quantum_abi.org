* Quantum engine C ABIs

NWChem, CPMD, MOPAC and CP2K run outside =librgpot=.
Each frontend (=NWChemPot=, =CPMDPot=, =MOPACPot=, =CP2KPot=) opens an engine
library with =dlopen= and calls the symbols declared in the headers below.
The four ABIs keep their own prefixes: =nwchemc_=, =cpmdc_=,
=mopacc_= and =cp2kc_=.
The generic engine table of [[file:engine_abi.org][Engine plugin ABI]] is a
separate interface with its own units.

The NWChem, CPMD and MOPAC engine libraries each ship with a stub that the
repository builds: the stub exports the same symbols, reports =*_available= as
0, fails every evaluation and returns the version string
=nwchemc-stub/1.0.0=, =cpmdc-stub/0.1.0= or =mopacc-stub/1.0.0=.
CP2K has no stub: instead, the repository builds the shim
=libcp2kc_rgpot= against =libcp2k= when =-Dwith_cp2k=enabled=.
A frontend that finds only a stub reports that the embed is not available.
The behaviour of a real engine beyond what the headers state is documented by
its own project; this page states what the headers promise, what the stubs do
and what the CP2K shim provides.

Units at these ABIs are not the units of =librgpot=.
Geometry is in Angstrom (Bohr for CP2K), energy in Hartree and gradients in
Hartree/Bohr; the frontends convert to Angstrom, eV and eV/Angstrom.
Options cross the ABI as an unpacked flat Cap'n Proto message for NWChem and
CPMD (root =NWChemParams= or =CPMDParams=, see
[[file:capnp_schema.org][the schema]]), as the packed struct =MopacCParams= for
MOPAC, and as input-deck text for CP2K.

** NWChem: =nwchem_c_abi.h=

The header is =CppCore/rgpot/NWChemPot/nwchem_c_abi.h=.
=RGPOT_NWCHEMC_API= expands to
=__declspec(dllexport)= when =RGPOT_NWCHEMC_BUILD= is defined on Windows and to
nothing elsewhere.

*** =NWChemCResult=

- Inputs :: none; a struct returned by value.
- Units :: =energy_h= is in Hartree.
- Outputs :: =ok= (1 on success, 0 on failure), =energy_h= (total energy), and
  =message=, a NUL-terminated status or error text of at most 512 bytes.
- Errors :: none; a failure is =ok= equal to 0 with the reason in =message=.

*** =nwchemc_set_params=

#+attr_rgpot: signature
#+begin_src c
int nwchemc_set_params(const void *params_capnp, size_t params_capnp_size_bytes);
#+end_src

- Inputs :: =params_capnp=, an unpacked flat =NWChemParams= message, and its
  size in bytes.
- Units :: none.
- Outputs :: 0 on success.
  The method options are kept for later calls.
- Errors :: non-zero when the embed is unavailable or the parameters are
  invalid; the stub always returns -1.

*** =nwchemc_energy_gradient=

#+attr_rgpot: signature
#+begin_src c
NWChemCResult nwchemc_energy_gradient(int n_atoms, const double *positions_ang, const int *atomic_numbers, const void *params_capnp, size_t params_capnp_size_bytes, double *grad_h_bohr);
#+end_src

- Inputs :: =n_atoms=; =positions_ang=,
  3*n doubles, row-major xyz; =atomic_numbers=, n atomic numbers; =params_capnp= and its size, as for =nwchemc_set_params=; =grad_h_bohr=, room for 3*n
  doubles.
- Units :: positions in Angstrom, energy in Hartree, gradient in Hartree/Bohr.
- Outputs :: an =NWChemCResult= with the energy, and the gradient written to
  =grad_h_bohr= row-major.
- Errors :: =ok= equal to 0 with the reason in =message=.
  The stub returns that with the text "NWChem embed not available (stub)" and
  the hint to provide =libnwchemc.so= on the dlopen path.

** CPMD: =cpmd_c_abi.h=

The header is =CppCore/rgpot/CPMDPot/cpmd_c_abi.h=.
The engine is =libcpmdc=, documented at
[[https://cpmdc.rgoswami.me][cpmdc.rgoswami.me]].
Two call styles exist.
The one-shot calls take the parameter message on every call.
A session holds the parameters once, and each step then passes a serialized
=ForceInput= and receives an unpacked flat =PotentialResult=.
Positions are in Angstrom and energies in Hartree.
A gradient is in Hartree/Bohr; a force is the negative of a gradient.
The result-message calls convert to =ForceInput.energyUnit= and
=energyUnit / lengthUnit=.

*** =CPMDCResult=

- Inputs :: none; a struct returned by value.
- Units :: =energy_h= is in Hartree (the CPMD native energy).
- Outputs :: =ok= (non-zero on success), =energy_h=, and =message=, a
  NUL-terminated status or error text of at most 512 bytes.
- Errors :: none; a failure is =ok= equal to 0 with the reason in =message=.

*** =CPMDCSession=

- Inputs :: none; an opaque type, created by =cpmdc_session_create=.
- Units :: none.
- Outputs :: a handle for repeated evaluations with one parameter set.
  It owns a copy of the serialized parameters, so the caller may free its buffer
  after creation.
- Errors :: none.
  Destroy it with =cpmdc_session_destroy=.

*** =CPMDCFeatureKind=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =CPMDC_FEATURE_SECTION= (1), =CPMDC_FEATURE_PARAMS= (2),
  =CPMDC_FEATURE_ABI= (3) and =CPMDC_FEATURE_KEYWORD= (4).
- Errors :: none.

*** =CPMDCFeatureEntry=

- Inputs :: none; a struct.
- Units :: none.
- Outputs ::
  =feature_id=, a string such as =section.dft= or =catalog.section.DFT=; =kind=, a =CPMDCFeatureKind=; =stub_applicable=
  and =embed_applicable=, non-zero when the feature applies to the stub and to
  the real embed.
- Errors :: none.

- Inputs :: =params_capnp=, an unpacked flat =CPMDParams= message, and its size

#+end_src

- Inputs :: =n_atoms=; =positions_ang=,

*** =cpmdc_session_select_orbitals=

#+attr_rgpot: signature
#+begin_src c
int cpmdc_session_select_orbitals(CPMDCSession *session, long long key);
#+end_src

- Inputs :: =session= and =key=, the name of the calculation the next
  evaluations belong to.
  The engine keeps the converged orbitals per key, so a calculator that
  evaluates several images or beads in turn starts each SCF from that image's or
  bead's own previous orbitals.
  The symbol is optional: an engine without it keeps one stored copy.
- Units :: none.
- Outputs :: 0 when =session= is non-null and the runtime accepts =key=.
  A new key is seeded from the session's current orbitals, and a key with a
  stored copy gets those orbitals back.
- Errors :: -1 when =session= is NULL, =key= is refused, or the library is the
  stub; the session's active key and orbitals are then unchanged.

- Units :: none.
- Outputs :: 0 after the orbitals stored under
  =from_key= are copied to =to_key=.
- Errors :: -1 when either key is invalid or unsupported; the stub returns -1.

** MOPAC: =mopac_c_abi.h=

The header is =CppCore/rgpot/MOPACPot/mopac_c_abi.h=; it must stay in lockstep
with =mopacc.h= of the =mopacc= project.
Options are the packed struct =MopacCParams=, not Cap'n Proto.
The version macros =RGPOT_MOPACC_C_ABI_VERSION= and =MOPACC_ABI_VERSION= are 2.
ABI 2 added =epsilon= and =solver= on =MopacCParams=, and
=dipole_debye= and =stress_gpa= on =MopacCResult=.
A caller compares both versions, and =mopacc_result_size= and
=mopacc_params_size= with its own sizes, before a call that returns
=MopacCResult=.
The model codes are =MOPACC_MODEL_PM7= (0),
=MOPACC_MODEL_PM6_D3H4= (1), =MOPACC_MODEL_PM6_ORG= (2), =MOPACC_MODEL_PM6= (3),
=MOPACC_MODEL_AM1= (4) and =MOPACC_MODEL_RM1= (5).

*** =MopacCParams=

- Inputs :: none; a struct.
- Units :: none stated by the header; the fields are those of
  =MOPACPot::Config=.
- Outputs :: =charge=, =spin=, =model= (a =MOPACC_MODEL_*= code), =tolerance=,
  =max_time= (seconds; 0 uses 3600), =epsilon= (COSMO dielectric; 1.0 is vacuum
  and must be 1 when a cell is set) and =solver= (0 conventional, 1 MOZYME).
  =MOPACPot::Config= defaults are charge 0, spin 0, model 4 (AM1), tolerance 1.0
  and max_time 3600.
  The constructor copies those into the packed struct and sets =epsilon= to 1.0
  and =solver= to =MOPACC_SOLVER_MOPAC= (0).
- Errors :: none.

*** =MopacCResult=

- Inputs :: none; a struct returned by value.
- Units :: =energy_h= is in Hartree, =dipole_debye= is in Debye and =stress_gpa=
  is in GPa.
- Outputs :: =ok=, =energy_h=, =dipole_debye= (three components), =stress_gpa=
  (Voigt xx, yy, zz, yz, xz, xy; 0 if unavailable) and =message=, a
  NUL-terminated text of at most 512 bytes.
- Errors :: none; a failure is =ok= equal to 0 with the reason in =message=.

** CP2K: =cp2kc_abi.h=

The header is =CppCore/rgpot/CP2KPot/cp2kc_abi.h=.
The shim =libcp2kc_rgpot= owns the libcp2k state: initialisation, the MPI
communicator, one force environment per orbital key, and the SCF convergence
check.
It speaks CP2K's atomic units and takes no Cap'n Proto.
Positions and cell vectors arrive in Bohr, the energy leaves in Hartree and the
forces in Hartree/Bohr.
Every rank of a calculator calls the session functions together, in the same
order and with the same arguments.
The macro =CP2KC_ABI_VERSION= is 1.
The return codes of =cp2kc_session_calculate= are
=CP2KC_OK= (0), =CP2KC_BAD_ARGUMENT= (1), =CP2KC_SCF_NOT_CONVERGED= (2) and
=CP2KC_FATAL= (-1, and any other negative value).

*** =CP2KCSession=

- Inputs :: none; an opaque type, created by =cp2kc_session_create=.
- Units :: none.
- Outputs :: a handle that owns every force environment of the session.
- Errors :: none.
  Destroy it with =cp2kc_session_destroy=.

*** =cp2kc_session_calculate=
