* C++ support types

=meson.build= installs every header under =CppCore/rgpot=, so each type declared
there at namespace scope is part of the C++ surface.
This page covers the value types, handles, enums and helper classes that the
potential classes of [[file:cpp_potentials.org][C++ potentials]] and
[[file:cpp_backends.org][C++ engine-backed potentials]] take or return.
Nested types are described with the type that holds them.
The UMA loader keeps its archive and executable-stack helpers in
=aoti_unpack.hpp= and =aoti_execstack.hpp=; they implement =UmaPot= and are not
a supported interface.

Lengths are in Angstrom, energies in eV and forces in eV/Angstrom unless an
entry says otherwise.

** Batches and handles

*** =rgpot::types::AtomMatrix=

- Inputs :: =AtomMatrix(rows, cols)=, =AtomMatrix()=, or a nested initializer
  list; =AtomMatrix::Zero(rows, cols)= builds a zero matrix.
- Units :: none; the units are those of the data stored.
- Outputs :: a row-major matrix of doubles.
  =operator()(row, col)= reads or writes an element, =rows()=, =cols()= and
  =size()= give the extents, and the raw data pointer is available for mutation
  and for reading.
  Positions and forces cross the =PotentialBase::operator()= interface as
  =n x 3= matrices.
- Errors :: none declared; an index outside the matrix is the caller's error.

*** =rgpot::BatchInput=

- Inputs :: none; a struct.
- Units :: Angstrom for =positions= and =box=.
- Outputs :: one configuration: =positions= (an =AtomMatrix=), =atomic_numbers=
  and =box=, a 3 by 3 array with one cell vector per row.
- Errors :: none.

*** =rgpot::BatchResult=

- Inputs :: none; a struct.
- Units :: eV, eV/Angstrom and eV^2.
- Outputs :: =energy=, =forces= (an =AtomMatrix=) and =variance= of one
  configuration.
- Errors :: none.

*** =rgpot::BatchEvaluator=

- Inputs :: a =PotentialFactory= (a =std::function= that returns a
  =std::unique_ptr<PotentialBase>=) and =n_threads=, where 0 selects the
  hardware concurrency, at least 1.
  =evaluate(inputs)= takes a vector of =BatchInput=.
- Units :: those of the potential.
- Outputs :: an evaluator that owns one potential per worker, built by calling
  the factory once per worker.
  =evaluate= splits the inputs into contiguous ranges, one per worker, and
  returns a vector of =BatchResult= in which element =i= answers input =i=.
  The potentials share nothing, so no potential has to be reentrant across
  threads.
  =n_threads()= reports the worker count.
- Errors :: an empty factory or a factory that returns a null potential throws
  =std::invalid_argument= from the constructor.
  A worker that throws stops its range, and =evaluate= rethrows the exception of
  the lowest-numbered failing worker after every worker has joined.

*** =rgpot::DynLib=

- Inputs :: an optional library path.
- Units :: none.
- Outputs :: a move-only handle on a shared library.
  =open(path)=, =close()= and =valid()= manage it, and =sym<T>(name)= and
  =sym_optional<T>(name)= resolve a symbol.
  The =MOPACPot= and =NWChemPot= directories each carry one; the class is the
  same on both.
- Errors :: =open= and =sym= throw
  =std::runtime_error= when the library or a required symbol is missing; =sym_optional=
  returns a null pointer.

*** =rgpot::MEAMLattice=

- Inputs :: one of the reference-structure enumerators from =FCC= through =SC=.
- Units :: none.
- Outputs :: the lattice used to build a MEAM element or mixed pair.
  =meam_lattice_from_name= parses the library spelling, and =meam_coordination=
  returns its first-neighbour count.
- Errors :: the parser returns false for an unknown or disallowed lattice.

*** =rgpot::MEAMElement=

- Inputs :: one MEAM library record: its name, reference lattice, atomic number,
  mass, decay lengths, lattice constant, cohesive energy, embedding constant,
  angular weights, density scale and =ibar= selector.
- Units :: Angstrom for lengths, eV for energy and g/mol for mass.
- Outputs :: the immutable element record consumed by =rgpot::MEAMParameters=.
- Errors :: validation occurs when the parameter or model object is built.

*** =rgpot::MEAMParameters=

- Inputs :: a nonempty vector of =rgpot::MEAMElement= records.
  =set= applies a parameter-file key to zero, one, two or three zero-based
  element indices, according to the key.
- Units :: eV and Angstrom.
- Outputs :: the element table and all scalar, pair and triple parameters used
  to build a model.
- Errors :: the constructor and =set= throw =std::invalid_argument= for an
  invalid lattice, density, index count, index or key value.

*** =rgpot::MEAMModel=

- Inputs :: a completed =rgpot::MEAMParameters= value.
- Units :: eV and Angstrom.
- Outputs :: immutable mixed parameters, reference densities and cubic pair
  tables.
  Its accessors expose the radial cutoff, screening radius, element records,
  pair values and angular-density functions.
- Errors :: construction throws =std::invalid_argument= when a table cannot be
  built, including an unsupported =ibar=, a second-neighbour C11 pair or a
  nonpositive cutoff width.

*** =rgpot::Fnv1a=

- Inputs :: bytes, doubles, integers, booleans or strings fed through =bytes=,
  =f64=, =i64=, =u64=, =b8= and =str=.
- Units :: none.
- Outputs :: a 64-bit FNV-1a state in =h=, starting at 0xcbf29ce484222325 with
  prime 0x100000001b3.
  A double is hashed by its bit pattern and a string by its length and then its
  bytes.
  Potentials fingerprint their configuration field by field into
  =PotentialBase::paramsKey()= with it, so cached results never cross parameter
  sets; a struct is never hashed by its bytes because of padding.
- Errors :: none.

*** =rgpot::cache::EvalCounts=

- Inputs :: none; a struct returned by =PotentialCache::counts=.
- Units :: none.
- Outputs :: =computed=, the results the kernel produced while the cache was
  attached, and =served=, the results answered from the cache without running
  the kernel.
- Errors :: none.

*** =rgpot::cache::KeyHash=

- Inputs :: a =uint64_t= hash, which is 64 bits on every platform.
- Units :: none.
- Outputs :: the numeric key of a configuration, in the public member =hash=.
  The cache stores it under a key of one version byte and the eight bytes of the
  hash in little-endian order.
- Errors :: none.

*** =rgpot::cache::PotentialCache=

- Inputs ::
  =PotentialCache(db_path, create_if_missing = true)= opens a RocksDB database; the default constructor holds none, and =set_db=
  adopts an open one.
- Units :: none; the stored energy, forces, variance and stress are in the units
  of the potential that produced them.
- Outputs :: a result cache.
  =add_serialized= stores a configuration, =deserialize_hit= reads one back, and
  =counts()= and =reset_counts()= read and zero the computed and served
  counters, which are atomic.
  Records keep the energy and force prefix and append versioned variance and
  stress metadata; energy-and-force-only records stay readable.
  The database mutex covers the database handle only.
- Errors :: see =rgpot.PotentialCache= for a database that cannot be opened.
  Available only when the library is built with RocksDB (=rgpot.has_cache=).

** Hessian-vector products

*** =rgpot::HvpScheme=

- Inputs :: none; an enum whose values match =rgpot_hvp_scheme_t=.
- Units :: none.
- Outputs :: =Auto= (0; analytic when the potential has it, otherwise
  =Forward=), =Forward= (1; one displaced force call against the cached centre),
  =Central= (2; two displaced force calls, one on each side) and =Analytic= (3;
  the potential's =hessianVectorImpl=).
- Errors :: =Analytic= is refused for a potential without =hessianVectorImpl=.

*** =rgpot::HvpCentre=

- Inputs :: none; a struct.
- Units :: eV, eV^2 and eV/Angstrom.
- Outputs :: =energy=, =variance= and =forces=, 3 * =nAtoms= doubles in
  row-major order, at a centre geometry.
- Errors :: none.

*** =rgpot::HvpCounts=

- Inputs :: none; a struct whose fields match =rgpot_hvp_counts_t=.
- Units :: none.
- Outputs :: =products= (products answered), =forceCalls= (force evaluations
  made), =centreReused= (requests served from the cached centre) and =analytic=
  (products taken from =hessianVectorImpl=).
- Errors :: none.

*** =rgpot::HessianVectorCache=

- Inputs :: none to construct; a non-copyable object.
  =centre(pot, in)= takes a potential and a =ForceInput=.
  =apply(pot, in, v, hv, step = 0.0, scheme = HvpScheme::Auto)= takes a
  direction =v= and an output =hv=, each 3 * =in.nAtoms= doubles that must not
  overlap.
- Units :: Angstrom for =step=, which is the displacement along the direction; 0
  selects =kHvpDefaultStep= (1.0e-3).
  The product has units eV/Angstrom^2 times the direction.
- Outputs :: =centre= returns the energy and forces at =in=, served from the
  cached centre when positions, species and cell carry the same bits, and
  otherwise from one force call that becomes the centre.
  =apply= writes the product H v to =hv=; a zero direction gives a zero product
  without a call.
  =counts()= returns an =HvpCounts=, =resetCounts()= zeroes it while the centre
  stays, and =invalidate()= drops the centre, which a caller must do when the
  potential changes while the geometry does not.
  The cache may be shared between threads; the lock covers the cached centre,
  not the force calls.
- Errors ::
  =std::invalid_argument= for a malformed request and =std::domain_error= when
  the kernel returns a non-finite value.

*** =rgpot::DerivativeReport=

- Inputs :: none; a struct returned by =GradientJet::gradientJet=.
- Units :: =operations= is a count; =scale= is in the units of the returned jet,
  eV/Angstrom for a direction in Angstrom.
- Outputs :: =tracked=, =operations= and =scale=.
  When =tracked= is true, =operations= times the machine epsilon times =scale=
  is a first-order estimate of the roundoff of the returned derivatives, not a
  rigorous bound.
  For a batch =operations= is the sum and =scale= the largest value over the
  systems.
  The engine table copies it into =RgpotEngineDerivativeReport= and writes zero
  =operations= and =scale= when =tracked= is false; =rgpot_core::engine= reads
  it back as =DerivativeReport= with an unsigned =operations=.
- Errors :: none.

*** =rgpot::GradientJet=

- Inputs :: an abstract interface that a potential derives next to
  =Potential<Derived>=, declared in =rgpot/GradientJet.hpp=.
  =gradientJet(systems, nAtoms, positions, atomicNrs, boxes, directions, order, jet)=
  takes =systems= systems that share =nAtoms= atoms and =atomicNrs=, with
  =positions= and =directions= of =systems * 3 * nAtoms= values, =boxes= of
  =systems * 9= values and an =order= from 1 to =maxJetOrder()=; the buffers
  must not overlap.
- Units :: positions, directions and cells in Angstrom; every block of =jet= is
  eV/Angstrom.
- Outputs :: =maxJetOrder()= returns the highest order the potential serves, at
  least 1.
  =gradientJet= writes =order * systems * 3 * nAtoms= values to =jet=, laid out
  =[order][system][3 * nAtoms]=: block =k - 1= of a system is the =k=-th
  derivative with respect to =t= of the gradient of the energy at
  =positions + t * direction=, at =t = 0=.
  Order 1 is the Hessian-vector product.
  It returns a =DerivativeReport= for the whole call.
  The engine table finds the interface with =dynamic_cast=.
  =PotentialBase= and its layout stamp therefore do not change.
  The table serves =rgpot_engine_taylor_jet= through the interface.
  It reports =maxJetOrder()= as =RgpotEngineCaps.jet_order=, which is 0 for a
  potential without the interface.
  =rgpot::CBEPot= implements it.
- Errors :: =maxJetOrder= is =noexcept=.
  =gradientJet= may throw; the engine table holds the jet in a scratch buffer
  and returns =RGPOT_ENGINE_ERR_EVAL= with the message, leaving the caller's jet
  and report untouched.
  The engine table refuses an order above =maxJetOrder()= with
  =RGPOT_ENGINE_ERR_UNSUPPORTED= before it calls the potential.

** Fused engine calls and kept potentials

*** =rgpot::FusedSource=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =Computed= when an answer came from the engine and =Stored= when it
  came from the stored entry.
- Errors :: none.

*** =rgpot::FusedSettingsSpec=

- Inputs :: none; a struct whose fields match =rgpot_fused_settings_t=.
- Units :: as the field names say.
- Outputs :: the engine settings that change the answer at a fixed geometry:
  =periodic= (bit i set means periodic along cell vector i), =spin= (the number
  of unpaired electrons), =sccMaxIterations=, =charge= (elementary charges),
  =accuracy=, =electronicTemperature= (Kelvin), =warmMove= (Angstrom, the
  wavefunction-reuse displacement), =warmMinGap= (eV, the reuse gap threshold),
  =sccMixer= and =engineBuild=.
- Errors :: none.

*** =rgpot::FusedFingerprint=

- Inputs :: none; a struct that compares equal field by field.
- Units :: floating-point fields are stored by bit pattern as 64-bit integers.
- Outputs :: everything but the positions that decides the answer of an engine
  call: the optional =atomicNumbers= and =cell= (nine bit patterns), =periodic=,
  =charge=, =spin=, =accuracy=, =electronicTemperature=, =warmMove=,
  =warmMinGap=, =sccMaxIterations=, =sccMixer=, =engineBuild= and =epoch=.
- Errors :: none.

*** =rgpot::FusedKey=

- Inputs :: none; a struct.
- Units :: none.
- Outputs :: the positions by bit pattern plus the =FusedFingerprint=.
  Equality is exact.
- Errors :: none.

*** =rgpot::SccNotConverged=

- Inputs :: the message string.
- Units :: none.
- Outputs :: an exception derived from =std::runtime_error= that reports a
  self-consistent field which did not converge.
- Errors :: none.

*** =rgpot::KeptKey=

- Inputs :: =f64(v)=, =i64(v)= and =ptr(v)= append an eight-byte field;
  =atoms(n, species)= sets the atom count and the species pointer, which may be
  null for a call without species and is read, not copied, until the key is
  kept.
- Units :: none.
- Outputs :: what a kept potential was built for.
  The key holds up to 16 eight-byte fields (=kBytes= is 128).
  A key that outgrows it never matches, so every call builds.
  The key compares bits: 0.0 and -0.0 differ and a NaN matches itself.
- Errors :: none; the methods are =noexcept=.

*** =rgpot::KeptCounts=

- Inputs :: none; a struct.
- Units :: none.
- Outputs :: =builds= and =reuses= of the potential type on one thread.
- Errors :: none.

** Locality, staging and parallel slices

*** =rgpot::Locality=

- Inputs :: none; a struct returned by a potential's =locality()= member.
- Units :: =cutoff= is in the length unit of the potential.
- Outputs :: =cutoff= (the range of a site energy; 0 declares no finite range),
  =pairwise= (every energy term is a function of one pair distance) and
  =densities= (values per atom that the density stage sums; 0 without
  densities).
  =finite()= is true for a positive cutoff, and =forceRange()= is =cutoff= for a
  pairwise potential and twice that otherwise: the distance within which the
  atoms set the force on one atom.
- Errors :: none.

*** =rgpot::PerAtomOut=

- Inputs :: none; a struct of two pointers.
- Units :: eV for energy; the virial is in energy units.
- Outputs :: =energy=, =nAtoms= entries that sum to =ForceOut::energy=, and
  =virial=, 6 * =nAtoms= entries (xx, yy, zz, yz, xz, xy per atom).
  A null pointer skips that quantity.
- Errors :: none.

*** =rgpot::HalfList=

- Inputs :: none; a struct that a host fills.
- Units :: =pos= is in the host's length unit.
- Outputs :: a host's half neighbour list over its own atoms and their copies.
  Atoms =[0, nOwned)= are owned and =[nOwned, nAtoms)= are copies.
  =pos= holds 3 * =nAtoms= coordinates and =atmnrs= one atomic number per atom.
  Row =k= belongs to owned atom =rows[k]=, whose neighbours are
  =neighbours[i][0 .. count[i])=, the layout of a LAMMPS =NeighList=.
  =indexMask= clears bits a host sets in an entry besides the index, and
  =newton= selects the case in which only one of two hosts that hold an owned
  and copy pair lists it, and the stages write the copy's share for the host to
  add to its owner.
  Entries beyond the cutoff are skipped, so a list built with a skin works.
- Errors :: none.

*** =rgpot::StageTally=

- Inputs :: none; a struct that =forceStage= fills.
- Units :: eV for energy; the virial is in energy units.
- Outputs :: the host's share of the energy and of the virial W = -V sigma in
  Voigt order (xx, yy, zz, yz, xz, xy), plus a =PerAtomOut=.
  The share is all of a pair that only this host lists, half of a pair both
  hosts list, and the site energy of each owned atom.
  A copy's per-atom entries are written only with =HalfList::newton=.
- Errors :: none.

*** =rgpot::Range=

- Inputs :: none; a struct.
- Units :: none.
- Outputs :: the items =[begin, end)= as two =std::int64_t= values.
  =partition(n, slice, nslices)= returns the contiguous run for a slice; the
  runs cover =n= without overlap, in slice order, and an out-of-range slice is
  empty.
- Errors :: none.

*** =rgpot::TeamCap=

- Inputs :: =TeamCap(threads)=.
- Units :: none.
- Outputs :: a scope guard.
  While it is alive, OpenMP regions this thread opens through =Slices.hpp= start
  at most =threads= threads; zero or less lifts the cap.
  Slices and results do not change.
  The previous cap returns on destruction, and the guard is not copyable.
- Errors :: none; the constructor is =noexcept=.

*** =rgpot::TeamFrom=

- Inputs :: none; a struct of three atom counts, =two=, =three= and =more=, each
  0 by default.
- Units :: atoms.
- Outputs :: the atom counts from which a team of two threads, of three, and of
  four or more opens.
  =of(threads)= returns =two= for two threads or fewer, =three= for three and
  =more= above that, and =least()= the smallest of the three.
  =teamSize(n, from, team)= and =forEachBatchSystem= take one; the default opens
  every team at =from=.
  A potential keeps its own as =kTeamFrom= in its class, and on any thread count
  sums atom by atom in index order from =least()=, its =kTeamMinAtoms=, so its
  bits do not depend on the thread count.
- Errors :: none; the members are =constexpr= and =noexcept=.

*** =rgpot::TeamThreshold=

- Inputs :: =TeamThreshold(atoms)=.
- Units :: atoms.
- Outputs :: a scope guard.
  While it is alive, a potential called on this thread takes =atoms= as its
  threshold in place of its own and opens a team on any thread count above one,
  so a benchmark can time every team on either side of its own threshold.
  =teamThreshold(own)= returns the threshold of the innermost guard alive on
  this thread, else =own=, and =teamThresholdActive()= reports whether one is
  alive.
  The bits still do not depend on the thread count, but a call between the two
  thresholds sums in the other order and its energy can differ in the last bits.
  The previous threshold returns on destruction, and the guard is not copyable.
- Errors :: none; the constructor is =noexcept=.

*** =rgpot::QuinticSwitch=

- Inputs :: =QuinticSwitch::endingAt(cutoff, width)= builds the switch over the
  last =width= Angstrom below =cutoff=; the fields are =r_on= and =inv_width=.
- Units :: Angstrom.
- Outputs :: the C^2 switch S(t) = 1 - 10 t^3 + 15 t^4 - 6 t^5 with t = (r -
  r_on) / (cutoff - r_on) clamped to [0, 1].
  =operator()(r)= returns =Value{s, dsdr}=, and =d2sdr2(r)= returns -60 t (1 -
  t) (1 - 2t) / w^2, where w is the width.
  Below =r_on= the switch is exactly 1, and at the cutoff it and its first two
  derivatives vanish.
- Errors :: =endingAt= throws =std::invalid_argument= unless 0 < width <=
  cutoff.

*** =rgpot::CentreDirect=

- Inputs :: =CentreDirect(i, force, energy, strain)=, with =strain= null when no
  strain is wanted.
- Units :: those of the potential.
- Outputs :: the terms of centre =i=, added to the totals as they come:
  =energy(e)=, =pair(a, j, sx, sy, sz)=, =triplet(a, j, b, k, scale, g1x, ...)=,
  =pairStrain= and =bondStrain=.
  =strained()= reports whether a strain accumulator exists.
- Errors :: none.

*** =rgpot::CentreTerms=

- Inputs :: =CentreTerms(strained)=; =reset(i, bonds)= starts centre =i= with
  one row per bond in the order of =bonds=, whose entries carry the partner in
  =.j=.
- Units :: those of the potential.
- Outputs :: the same calls as =CentreDirect=, summed per atom, so the
  contribution of one centre can be added to the totals in a fixed order with
  =addTo(force, energy, strain)=.
- Errors :: none.

*** =rgpot::CentreLedger=

- Inputs :: =keep(terms)= takes a finished =CentreTerms=.
- Units :: those of the potential.
- Outputs :: the finished centres of one slice, in the order they finished.
  =addTo(force, energy, strain)= adds each centre into the totals as
  =CentreTerms::addTo= would, and =clear()= empties the ledger.
- Errors :: none.

** Potential parameter types

*** =rgpot::D3Damping=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =BJ=, rational Becke-Johnson damping, and =Zero=, zero damping.
- Errors :: none.

*** =rgpot::EAMTableFormat=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =Funcfl= (LAMMPS =eam=, one element), =Setfl=
  (=eam/alloy=) and =FinnisSinclair= (=eam/fs=), the three file layouts of
  [[file:eam_table.org][Tabulated EAM]].
- Errors :: none.

*** =rgpot::EAMTable=

- Inputs :: none; a struct of tabulated functions after the LAMMPS file2array
  step.
- Units :: =drho= is in the density unit of the file, =dr=, =cutoff= in
  Angstrom, and energies in eV.
- Outputs :: =nrho=, =drho=, =nr=, =dr=, =cutoff=, =rhomax=, the atomic numbers
  =z= and the arrays =frho= (F_a, one per element), =rhor= (rho_ab at index
  =b * n + a=, the density element b puts at an a site) and =z2r= (r phi_ab at
  index =a (a + 1) / 2 + b= for a >= b).
  Entry =m= of an array sits at =m * dr= or =m * drho=.
- Errors :: none.

*** =rgpot::eam::Spline1D=

- Inputs :: none; a struct.
- Units :: =origin= and =h= are in the argument unit of the table.
- Outputs :: a uniform cubic Hermite table: =origin=, =h=, =inv_h=, =nseg= and
  the coefficient vector =c=; =eval(r)= evaluates it.
  The nodes sit close enough to keep a pair within 1e-12 relative of the
  analytic exponential it replaces.
- Errors :: none.

*** =rgpot::eam::ElementSpline=

- Inputs :: none; a struct.
- Units :: Angstrom for distances, eV for energies.
- Outputs :: one element's splines: =rho= (density), =fscale= (density force),
  =phi= (pair energy) and =fcomp= (pair force), with =Z=, =cutoff2=, a pointer
  =embed= to the embedding table, the grid constants =kOrigin= (0.05) and
  =kStep= (5e-5), and the methods =density=, =densityForce=, =pairEnergy= and
  =pairForce=.
- Errors :: none.

*** =rgpot::SuttonChenScales=

- Inputs :: none; a struct returned by =sutton_chen_scales(cfg)=.
- Units :: =nearest_neighbor= in Angstrom and =well_depth= in eV.
- Outputs :: the bulk nearest-neighbour distance and the positive cohesive well
  depth of the fcc crystal for a =SuttonChenConfig=.
- Errors :: none.

*** =rgpot::ZblPairCoeffs=

- Inputs :: none; a struct for one ordered pair of species.
- Units :: =zze= in eV Angstrom; the others are dimensionless coefficients.
- Outputs :: the screening exponents =d1= to =d4= scaled by the pair radius,
  =zze= (Z_i Z_j e^2), the quadratic and cubic switching coefficients of the
  force (=sw1=, =sw2=), the cubic and quartic coefficients of the energy (=sw3=,
  =sw4=) and the constant energy offset at the cutoff (=sw5=).
- Errors :: none.

*** =rgpot::ZblTables=

- Inputs :: none; a struct.
- Units :: see =ZblPairCoeffs=.
- Outputs :: the sorted unique atomic numbers =z= and the coefficients =pairs=,
  a =z.size()= by =z.size()= row-major table of =ZblPairCoeffs=.
- Errors :: none.

*** =rgpot::GFNMethod=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =GFNFF=, =GFN0xTB=, =GFN1xTB= and =GFN2xTB=, the methods of
  =XTBPot=.
- Errors :: none.

*** =rgpot::TBLiteMethod=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =GFN1=, =GFN2= and =IPEA1=, the methods of =TBLitePot=.
- Errors :: none.

*** =rgpot::TorchDeterminismPolicy=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =Fast= (0; leave process-global LibTorch state alone) and =Strict=
  (1; apply deterministic algorithms, the math attention backend, no TF32 and
  deterministic cuDNN).
  The flags are process-global.
- Errors :: none.

*** =rgpot::CP2KScfError=

- Inputs :: the message string.
- Units :: none.
- Outputs :: an exception derived from =std::runtime_error=, thrown when the SCF
  did not converge.
  The shim agrees on the outcome over the calculator's communicator, so every
  rank of the calculator throws it for the same call and no rank aborts the
  world.
  A caller may reject the geometry and continue.
- Errors :: none.

*** =rgpot::UmaContract=

*** =rgpot::nlist::Cut=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =Strict= keeps pairs with distance strictly below the cutoff;

*** =rgpot::nlist::Fields=

- Inputs :: none; a struct of three booleans, all true by default.
- Units :: none.
- Outputs :: =shifts=, =vectors= and =distances=, the arrays a table or chunk
  carries; an unset field is left empty rather than filled with zeros.
- Errors :: none.

*** =rgpot::nlist::Query=

- Inputs :: none; a struct.
- Units :: =cutoff= and =skin= in Angstrom.
- Outputs :: =cutoff=, =skin=, =shape= (a =Pairs= or =Cluster4=, default
  =Pairs{}=), =cut= (default =Strict=), =periodic= (all true) and =fields=.
  =build= and =Builder= store the pairs and =Walk= streams them; there is no
  setting that stores nothing.
- Errors :: =Error= with code =Cutoff=, =Shape=, =Skin= or =Box= when the query
  is rejected.

*** =rgpot::nlist::View=

- Inputs :: none; a struct of spans.
- Units :: =vector= and =distance= in Angstrom.
- Outputs :: a non-owning view of a structure-of-arrays table: =first=,
  =second=, =shift= (empty or three per pair), =vector= (empty or three per
  pair), =distance= and =mask= (one byte per pair; 0xff for a pair list, bits 0
  to 3 for a cluster of four).
  The spans are invalidated by the next rebuild of the table that owns them.
- Errors :: none.

*** =rgpot::nlist::Table=

- Inputs :: none; a struct.
- Units :: as =View=.
- Outputs :: the owning arrays =first=, =second=, =shift=, =vector=, =distance=
  and =mask=, the =device= (0 for host memory) and =stored=.
  =size()= is the pair count, =view()= returns a =View= and
  =column_major_vectors()= the vectors as a Fortran =(3, npairs)= array over the
  same memory.
- Errors :: none.

*** =rgpot::nlist::Systems=

- Inputs :: none; a struct of pointers.
- Units :: Angstrom.
- Outputs :: several systems that do not interact: =positions=, the
  concatenation of every system; =count=, the atoms of each; =systems=, their
  number; and =box9=, nine lattice values per system.
  A count of 0 is an empty system.
- Errors :: none.

*** =rgpot::nlist::Batch=

- Inputs :: none; a struct.
- Units :: as =Table=.
- Outputs :: the pairs of a =Systems= build: =pairs=, a =Table= whose =first=
  and =second= index the concatenated positions, and =system=, which names the
  system that owns each pair.
- Errors :: none.

*** =rgpot::nlist::Builder=

- Inputs :: =update(positions, n, box9, query)=.
- Units :: Angstrom.
- Outputs :: a stored list with a skin rebuild.
  A later update keeps the table while every atom has moved by at most half the
  skin and the cell and the query are unchanged; skin 0 rebuilds unless the
  coordinates match.
  =table()=, =builds()= and =reused()= report the table, the rebuild count and
  whether the last update kept the table.
  One thread uses a builder; two builders may update at the same time.
- Errors :: =Error= when the geometry is rejected; the previous table stays.

*** =rgpot::nlist::Buffers=

- Inputs :: none; a struct of spans.
- Units :: as =View=.
- Outputs :: caller-owned buffers for one chunk.
  =first= and =second= have the same length, the most pairs this pull writes;
  =shift= and =vector= are empty or three times that length; =distance= and
  =mask= follow the request.
- Errors :: none.

*** =rgpot::nlist::Walk=

- Inputs :: =Walk(positions, n, box9, query)=, which borrows =positions= and
  =box9= until it is destroyed; =pull(dest, done)= takes a =Buffers=.
- Units :: Angstrom.
- Outputs :: a stream of pairs for one central atom, or one cluster of four, at
  a time into caller storage, without a list of the whole system.
  =pull= returns the number of pairs written and sets =done= when the geometry
  is exhausted.
  One thread uses a walk.
- Errors :: a requested field whose span is too short throws =Error= and does
  not advance.

*** =rgpot::nlist::Image=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: how the minimum image is formed: =Round= is the orthorhombic
  truncation used by the pair kernels, =Half= is one correction about the
  half-box after coordinates have been wrapped, and =General= uses
  =MinimumImage= for a non-orthogonal cell or a periodic side shorter than the
  search.
- Errors :: none.

*** =rgpot::nlist::Mode=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: =Stored= keeps a Verlet list of candidate pairs; =Stream= walks the
  cells and stores nothing beyond the atoms and the bins; =Auto= stores when the
  candidate index fits in the memory the operating system reports as available
  and streams otherwise.
- Errors :: none.

*** =rgpot::nlist::Spec=

- Inputs :: none; a struct.
- Units :: =cutoff= and =skin= in Angstrom.
- Outputs :: =cutoff=, =skin=, =periodic= (all true), =image= (default =Round=)
  and =mode= (default =Auto=).
- Errors :: none.

*** =rgpot::nlist::MinimumImage=

- Inputs :: =MinimumImage(cell, periodic)=, a row-major cell of nine values and
  three periodic flags.
- Units :: Angstrom.
- Outputs :: the nearest periodic image d - n H. =fold(dx, dy, dz)= folds a
  displacement in place, and =foldWithin(dx, dy, dz, within2)= returns false
  when every image is longer than the squared length =within2=.
  A cell whose condition estimate would spend more than half the double
  significand is Minkowski-reduced, and a basis that is still ill-conditioned
  searches the 27 images with coefficients in -1, 0 and 1.
  The static =searches()= counts the folds on the calling thread that searched
  over images.
- Errors :: a singular or non-finite cell, or an index that does not fit in an
  =int64=, throws.

*** =rgpot::nlist::Neighbours=

- Inputs :: =update(xyz, n, box9, spec)=.
- Units :: Angstrom.
- Outputs :: candidate pairs around one configuration.
  A stored list is reused while every atom has moved by at most half the skin
  and the cell, the count and the spec are unchanged; skin 0 reuses it only when
  the coordinates and the cell match.
  An infinite cutoff or skin makes every pair a candidate, bins nothing and
  stores nothing.
  =forDirected=, =forHalf=, =forCellTeam= and the per-atom walks visit the
  pairs, =mode()=, =streaming()=, =allPairs()=, =reused()=, =builds()= and
  =slots()= report the state, and =offsets()= and =neighbours()= expose the
  stored index.
  Candidates lie inside the cutoff plus the skin; the caller drops the rest.
- Errors :: see =MinimumImage= for a rejected cell.

*** =rgpot::nlist::NeighborList=

- Inputs :: =skin=, the extra search distance in Angstrom.
- Units :: Angstrom.
- Outputs :: a reusable pair list for =orderedPairs=.
  A null list passed to =orderedPairs= rebuilds every call.
  The stored pairs (=lo=, =hi= and the folded =dx=, =dy=, =dz=) are reused while
  every atom has moved by at most skin/2 and the cell is unchanged; skin 0
  reuses the list only when the coordinates match.
  =use_stored= is true when =dx=, =dy= and =dz= match the current coordinates,
  and =clear()= drops the list.
- Errors :: none.

*** =rgpot::nlist::Overlap=

- Inputs :: none; an enum.
- Units :: none.
- Outputs :: what a pair of atoms on one point does: =Skip= ignores it and
  =Poison= makes the energy NaN.
- Errors :: none.
