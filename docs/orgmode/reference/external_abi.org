* External engine C ABI

=CppCore/rgpot/ExternalPot/external_potentials.h= declares the C constructors of
the LAMMPS, GROMACS and OpenMM shifted Lennard-Jones potentials.
=CppCore/rgpot/ExternalPot/ExternalPot.cc= implements them in =librgpot=.
Positions and cells are Angstrom, energies eV and forces eV/Angstrom at this
interface.
A box is nine doubles, the lattice vectors as rows.
Every call that can fail takes =err= and =err_len=.
On failure it writes a message of at most
=err_len - 1= characters and a terminating null into =err=; a null =err= or an =err_len=
of 0 writes nothing.

** Types

*** =rgpot_external_potential=

- Inputs :: none; an opaque handle from one of the constructors.
- Units :: none.
- Outputs :: none.
- Errors :: none.

One handle holds one potential.
Each potential serialises the force calls of its own instance with a mutex.

An engine library stays resident once a constructor opens it.
The first successful open is kept and marked =RTLD_NODELETE=, so the mapping
stays resident after =dlclose= and a later constructor of the same file reuses
that open instead of taking another reference.
An open that does not become the resident engine is closed after the constructor
releases its table lock.
=rgpot_external_potential_free= destroys the engine instance and leaves the
library mapped.
A backend may keep OpenMP, CUDA, MPI, GROMACS, LAMMPS or OpenMM state that does
not survive an unload.
A later constructor that opens the same file gets the dynamic linker's existing
handle.

** Constructors

*** =rgpot_lammps_potential=

#+attr_rgpot: signature
#+begin_src c
rgpot_external_potential *rgpot_lammps_potential(const char *engine_path,
                                                double u0, double cutoff,
                                                double psi, char *err,
                                                size_t err_len);
#+end_src

- Inputs :: =engine_path=, the engine library, or null or empty to search.
  =u0= is the well depth, =cutoff= the cutoff and =psi= the zero crossing of the
  12-6 potential.
  =err= and =err_len= receive a failure message.
- Units :: =u0= is eV; =cutoff= and =psi= are Angstrom.
- Outputs :: a new handle, freed with =rgpot_external_potential_free=.
  The constructor opens the engine library, resolves =rgpot_engine_create=,
  =rgpot_engine_destroy= and =rgpot_engine_force=, and calls
  =rgpot_engine_create= with the three doubles =u0=, =cutoff=, =psi= in eV and
  Angstrom.
  Every force call goes to =rgpot_engine_force=.
  A non-empty =engine_path= is the only library tried.
  Otherwise the constructor tries =RGPOT_LAMMPS_ENGINE=, then
  =LAMMPS_ENGINE= when they are set and not empty, then =liblammps_engine.so=
  and =liblj_engine.so= through the dynamic linker's search path (=.dylib= on
  macOS, =.dll= on Windows).
- Errors :: returns null and writes =err= when =u0=, =cutoff= or =psi= is not
  positive and finite ("u0, cutoff and psi must be positive and finite (eV and
  Angstrom)").
  Returns null and writes =err= when no candidate opens with all three symbols
  ("engine library was not opened: " and the reason for each candidate) or when
  =rgpot_engine_create= returns null (its message, or "rgpot_engine_create
  failed").
  Returns null and writes =err=, without trying the next candidate, when the
  opened file cannot be identified through =dladdr= and =realpath=, or when its
  canonical path was loaded before and now names another inode ("was replaced
  after it was loaded").

*** =rgpot_gromacs_potential=

#+attr_rgpot: signature
#+begin_src c
rgpot_external_potential *rgpot_gromacs_potential(const char *engine_path,
                                                 double u0, double cutoff,
                                                 double psi, char *err,
                                                 size_t err_len);
#+end_src

- Inputs ::
  =engine_path=, a library, or null or empty to evaluate in process; =u0=, =cutoff=, =psi=, =err= and =err_len=
  as in =rgpot_lammps_potential=.
- Units :: =u0= is eV; =cutoff= and =psi= are Angstrom.
  The constructor stores them once as kJ/mol and nm.
- Outputs :: a new handle, freed with =rgpot_external_potential_free=.
  Without a library the force is the in-process =LJPot= with =u0=, =cutoff= and
  =psi=.

  =rgpot_engine_destroy= and
  =rgpot_md_native_force=, and calls =rgpot_engine_create= with the three doubles in kJ/mol and nm. Each force call then passes positions and box in nm to =rgpot_md_native_force=
  and converts the
  kJ/mol energy and the (kJ/mol)/nm forces back to eV and eV/Angstrom.
- Errors :: returns null and writes =err= for a =u0=, =cutoff= or =psi= that is
  not positive and finite, a library that does not open or lacks one of the
  three symbols, a library that cannot be identified or was replaced, or a
  failed =rgpot_engine_create=, with the messages of =rgpot_lammps_potential=.

*** =rgpot_external_potential_energy_forces=

#+attr_rgpot: signature
#+begin_src c
int rgpot_external_potential_energy_forces(
    rgpot_external_potential *pot, const double *xyz, const int *atomic_numbers,
    size_t n, const double *box9, double *forces, double *energy, char *err,
    size_t err_len);
#+end_src

- Inputs :: =pot=, =xyz= (=3 * n= doubles, row-major =x y z= per atom),
  =atomic_numbers= (=n= ints), =box9= (nine doubles, lattice vectors as rows), =forces= (room for =3 * n= doubles), =energy=, =err= and =err_len=.
  =box9= must not be null, also when =n= is 0.
- Units :: =xyz= and =box9= are Angstrom, =*energy= is eV and =forces=
  eV/Angstrom.
- Outputs :: returns 0 and writes =*energy= and the =3 * n= forces, row-major
  like =xyz=.
  The variance the engine reports is not returned.
- Errors :: returns 1 and writes
  "energy_forces needs a potential and a geometry" for a null =pot=, =energy= or =box9=, or, when =n > 0=, a null =xyz=, =atomic_numbers=
  or =forces=. Returns 1 and writes the message when the evaluation throws, for
  example "rgpot_engine_force failed" or "rgpot_md_native_force failed" when the
  engine returns nonzero.

** Example

The GROMACS potential evaluated in process, a dimer 1.5 Angstrom apart.

#+attr_rgpot: run link=rgpot flags=-ICppCore,-Iinclude
#+begin_src c
#include <stdio.h>
#include "rgpot/ExternalPot/external_potentials.h"

int main(void) {
  char err[256] = "";
  rgpot_external_potential *pot = rgpot_gromacs_potential(NULL, 1.0, 8.0, 1.0, err, sizeof err);
  if (pot == NULL) {
    fprintf(stderr, "%s\n", err);
    return 1;
  }
  const double xyz[6] = {0.0, 0.0, 0.0, 1.5, 0.0, 0.0};
  const int z[2] = {1, 1};
  const double box9[9] = {20.0, 0.0, 0.0, 0.0, 20.0, 0.0, 0.0, 0.0, 20.0};
  double forces[6];
  double energy = 0.0;
  const int rc = rgpot_external_potential_energy_forces(pot, xyz, z, 2, box9, forces, &energy,
                                                        err, sizeof err);
  rgpot_external_potential_free(pot);
  if (rc != 0) {
    fprintf(stderr, "%s\n", err);
    return 1;
  }
  if (!(energy < 0.0) || forces[0] != -forces[3]) {
    return 1;
  }
  printf("%.10f eV, %.6f eV/Angstrom\n", energy, forces[0]);
  printf("%.6f kJ/mol per eV, %.1f nm per Angstrom\n", rgpot_md_kj_per_ev(),
         rgpot_md_nm_per_angstrom());
  return 0;
}
#+end_src

** Generic MD sessions

The
=rgpot_md_session_*= interface lets any dynamics backend (OpenMM, GROMACS nblib, LAMMPS) implement one vtable in rgpot units: positions and plane/wall coordinates in Angstrom, velocities in Angstrom/ps, forces in eV/Angstrom, energies and =kT= in eV, =time_step=
in ps, =friction= in ps^-1, masses in amu, and the periodic box in Angstrom
(nine doubles, the lattice vectors as rows).

A sampler such as a hyperplane, PAFI, OH-TST, Bennett-Chandler or forward-flux
driver needs only these calls, and none of them is special to one engine:
positions, velocities and the box are set and read;
=rgpot_md_session_run_langevin= steps Langevin dynamics with a time step, a
friction and a seed, on a hyperplane with a holonomic constraint force reported
per step, between planar walls that reflect or reject the drift;
=rgpot_md_session_reseed_velocities= draws Maxwell-Boltzmann velocities; and the
energies and forces are read back.
The random stream is the same on every engine: the draws are made by rgpot, not
by the backend.

*** Random streams

=seed= names a stream.
A call with the seed of the previous call continues the stream, with its
Box-Muller spare, so a run split in chunks equals one long run.
A different seed starts a new stream.
Setting positions or velocities ends the stream, so the same seed after a new
state replays the same noise.
Two sessions given the same states and seeds draw the same numbers.

*** Constraint force

With a plane =n . (x - p) = 0=, run_langevin reports for each step the Lagrange
multiplier =lambda = -(n . M^-1 F) / (n . M^-1 n)= for the unit normal =n= over
the =3N= coordinates and the mass matrix =M=, in eV/Angstrom: the mean of the
two force kicks of the step.
The constraint force on the system is =lambda n=.
For a plane of fixed normal the mean of =lambda= over the constrained ensemble
is =dF/dc= for the plane offset =c = n . p=, which PAFI integrates and the
Bennett-Chandler transmission coefficient needs.
A backend with distance constraints of its own topology holds them along with
the plane, and the multiplier of the plane accounts for them.

*** =rgpot_md_session=

- Inputs :: none; an opaque handle from =rgpot_md_session_from_ops= or
  =rgpot_md_session_create=.
- Units :: none.
- Outputs :: none.
- Errors :: none.

*** =rgpot_md_session_ops=

- Inputs :: =struct_size= (=sizeof(rgpot_md_session_ops)=) and backend callbacks
  =set_positions=, =set_velocities=, =step_langevin=, =step_nve=,
  =get_state=, =get_masses=, and =destroy=, followed by the optional
  =set_periodic_box=, =get_periodic_box=, =initialize=,
  =run_langevin=, =get_neighbors=, and =set_neighbors=.
  The macro =RGPOT_MD_OPS_HAS(ops, member)= tests that a vtable carries an
  optional member.
- Units :: rgpot host units (Angstrom, eV, ps, amu).
- Outputs :: vtable consumed by =rgpot_md_session_from_ops= and exported by
  engine plugins implementing =rgpot_md_session_engine_create_fn=.
- Errors :: =rgpot_md_session_from_ops= rejects null required callbacks or a
  =struct_size= that ends before =destroy=.
  A vtable that ends earlier than an optional member, or leaves it null, makes
  that call fail with a message naming the missing callback.

*** =rgpot_md_langevin_request=

- Inputs :: =struct_size=, =kT=, =friction=, =time_step=, =steps=, =seed=, =n3=,
  =plane_point= and =plane_normal= (both null for no plane),
  =n_walls= with =wall_points= and =wall_normals= of =n_walls * n3= doubles, and
  =wall_mode= (=RGPOT_MD_WALL_REFLECT= or =RGPOT_MD_WALL_REJECT=).
- Units :: =kT= in eV, =friction= in ps^-1, =time_step= in ps, points in
  Angstrom.
- Outputs :: none; the argument of =rgpot_md_session_run_langevin=.
- Errors :: a =struct_size= below =sizeof(rgpot_md_langevin_request)= is
  rejected.

*** =rgpot_md_langevin_result=

- Inputs :: =struct_size=, and =constraint_force= with its length
  =constraint_force_len=, or null.
- Units :: =constraint_force= in eV/Angstrom.
- Outputs :: =wall_hits=, and one multiplier per step in =constraint_force= when
  a plane is set; nothing is written without a plane.
- Errors :: a =constraint_force_len= below the number of steps is rejected.
