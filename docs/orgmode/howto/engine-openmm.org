* OpenMM

OpenMM has no callback that can call an arbitrary C++ potential.
The comparison that the meson test
=openmm_lj= runs (=engines/openmm/run_openmm.py=) is a =CustomNonbondedForce=
whose expression is the shifted 12-6 potential rgpot evaluates, written in
OpenMM's nanometres and kJ/mol.

The energy is one expression with no named subexpressions.
Sigma and epsilon are combined geometrically, which is exact when both atoms
carry the same parameters, as they do in the test.

Positions are 0 and 0.15 nm in a 2 nm cube, cutoff 0.8 nm.
The context energy, converted with =rgpot-lj --kJ-per-eV=, matches the direct
evaluation to 1e-6 eV, and the force on the second atom matches to 1e-5
eV/Angstrom.
The test runs when the =openmm= Python module imports.
=-Dwith_openmm=enabled= makes a missing =openmm= module a configure error.

** Public constructor

=rgpot_openmm_potential= stores the same nanometre and
kJ/mol factors as =rgpot_gromacs_potential=; =rgpot_md_kj_per_ev()= and =rgpot_md_nm_per_angstrom()= return them. It takes =u0= in eV and =cutoff= and =psi= in Angstrom. An empty engine path (=NULL= or =""= in C) evaluates the potential in process, in Angstrom and eV. A non-empty path is a library that exports =rgpot_engine_create=, =rgpot_engine_destroy= and =rgpot_md_native_force= in nanometres and kJ/mol,
such as =libopenmm_engine.so=; a library that lacks one of them is refused.
That library evaluates the shifted 12-6 expression with an OpenMM
=CustomNonbondedForce= on the CPU platform.
The constructor converts =u0=, =cutoff= and =psi= to the library's units once
and passes them to =rgpot_engine_create=.
Every call then converts the positions and the box to nanometres and the energy
and forces back to eV and eV/Angstrom.
=rgpot_external_potential_energy_forces= returns 0 and that result, or 1 with a
message in =err=, and =rgpot_external_potential_free= releases the potential.
The errors are the same as for =rgpot_gromacs_potential=: the C constructor
returns =NULL= and writes =err=.

** In-process dynamics session

When OpenMM is enabled, =rgpot/ExternalPot/OpenMM.hpp= also exposes
=rgpot::OpenMMSession= (in OpenMM native units: nm, kJ/mol, ps, amu).
It takes an owned =OpenMM::System= and creates the selected platform in the same
process.
=setPositions= and =setVelocities= initialize the context; =state= reads
positions, velocities, forces, and both energies.

=stepLangevin= and =runLangevin= run projected BAOAB splitting on a full
=3N=-dimensional hyperplane using the inverse-mass metric (matching Euclidean
projection in mass-weighted coordinates), through the engine-independent driver
in =rgpot/MDSession/ProjectedLangevin.hpp=.
The first force of a call is evaluated on the hyperplane, positions are restored
after each half-drift, and optional planar walls reflect specularly as often as
a drift needs, or reject the drift.
=runLangevin= also returns the Lagrange multiplier of the plane per step.
Distance constraints serialized in the =System= hold along with the hyperplane;
a =System= with virtual sites is refused.
The random stream is held by the session: a call with the seed of the previous
call continues it, a new seed starts a new stream, and setting positions or
velocities ends it.
The return value of =stepLangevin= is the number of wall reflections.
=stepNVE= advances unconstrained deterministic velocity-Verlet updates on the
same OpenMM Context.

The generic C ABI =rgpot_md_session_*= (=external_potentials.h=) wraps any
engine via =rgpot_md_session_ops= or =rgpot_md_session_create= in rgpot units
(Angstrom, eV,
eV/Angstrom, ps, amu); =libopenmm_engine.so= exports =rgpot_md_session_engine_create= and converts between Angstrom/eV
and OpenMM's nm/kJ/mol, including the periodic box. In Rust,
=rgpot_core::md_session= exposes =MdSession=, =MdLangevinConfig=,
=MdSessionState=, and =CAbiMdSession=. The optional
neighbour exchange slots use the shared =rgpot_nlist_request= and
=rgpot_nlist_soa= columns: =rgpot_md_session_get_neighbors= queries the
current Context geometry and box through rgpot's shared neighbour builder,
while =rgpot_md_session_set_neighbors= reports
=RGPOT_MD_NLIST_UNSUPPORTED= for OpenMM today.

The test =openmm_analytic= drives a chain of three atoms with harmonic bonds of
rest length zero on a hyperplane through the C ABI and checks the kinetic and
potential energy and the mean constraint force against their closed forms,
=dF/dc= among them, within the batch-means standard error; it also checks seeded
replay and Maxwell-Boltzmann reseeding.
The test =openmm_abi= checks the box in Angstrom, the constraint force per step,
and the errors for a short vtable.
The cases =openmm_review_*= check the equipartition, the mean force, the first
force on the plane, seeding across calls, serialized constraints, and walls
crossed many times.

The OpenMM session test checks harmonic energy and force, samples a free
two-particle system with unequal masses on a =3N= hyperplane against the target
kinetic temperature, checks wall reflections, determinism across 64-bit seeds,
unconstrained NVE after Langevin stepping, and the C ABI unit conversions and
error handling.
It uses =Reference= in the test; applications can select =CPU= or =CUDA= through
=OpenMMSessionConfig::platform=.

Meson builds =libopenmm_engine.so= when the =openmm= Python module reports its
library path and =libOpenMM= and =openmm/Platform.h= are found there.
With =-Dwith_openmm=enabled=, a missing =libOpenMM= there is a configure error.
The meson test =external_potentials= then loads it through =RGPOT_OPENMM_ENGINE=
and checks the dimer at 1.5 Angstrom: -0.3203213355 eV from =rgpot-lj=, matched
to 1e-6 eV, and the force on the second atom to 1e-5 eV/Angstrom.
When the library was not built, the test prints a =SKIP openmm engine= line with
that reason and still passes.

#+begin_src python
import numpy as np
import rgpot

pot = rgpot.rgpot_openmm_potential(1.0, 8.0, 1.0)
energy, forces, variance = pot(
    np.array([[0.0, 0.0, 0.0], [1.5, 0.0, 0.0]]),
    [1, 1],
    np.diag([20.0, 20.0, 20.0]),
)
assert f"{energy:.10f}" == "-0.3203213355"
#+end_src

#+attr_rgpot: run link=rgpot
#+begin_src c
#include "rgpot/ExternalPot/external_potentials.h"

#include <stdio.h>

int main(void) {
  char err[256] = "";
  const double xyz[6] = {0, 0, 0, 1.5, 0, 0};
  const int z[2] = {1, 1};
  const double box[9] = {20, 0, 0, 0, 20, 0, 0, 0, 20};
  double forces[6];
  double energy = 0.0;
  rgpot_external_potential *pot =
      rgpot_openmm_potential(NULL, 1.0, 8.0, 1.0, err, sizeof err);
  if (pot == NULL) {
    fprintf(stderr, "%s\n", err);
    return 1;
  }
  if (rgpot_external_potential_energy_forces(pot, xyz, z, 2, box, forces,
                                             &energy, err, sizeof err) != 0) {
    fprintf(stderr, "%s\n", err);
    rgpot_external_potential_free(pot);
    return 1;
  }
  printf("%.10f eV\n", energy);
  rgpot_external_potential_free(pot);
  return 0;
}
#+end_src
