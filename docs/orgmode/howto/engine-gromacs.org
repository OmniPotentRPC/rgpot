* GROMACS

GROMACS 2026's NNPot module loads a TorchScript model.
The conda-forge build used here has no NNPot.
It does accept =gmx mdrun -plumed=.
The collective variable =RGPOT= calls the same Lennard-Jones evaluator as the
other engines, and =BIASVALUE= applies that energy as the bias.
A topology with zero charge and zero Lennard-Jones leaves the bias as the only
potential.

Parameters in the PLUMED file are in GROMACS units: nanometres and kJ/mol.
=U0= for a 1 eV well is the factor =rgpot-lj --kJ-per-eV= prints.
=CUTOFF= 0.8 and =PSI= 0.1 are 8 Angstrom and 1 Angstrom.

#+begin_src text
ene: RGPOT ATOMS=1,2 U0=96.48533212331002 CUTOFF=0.8 PSI=0.1
b: BIASVALUE ARG=ene
PRINT ARG=ene FILE=COLVAR
#+end_src

=gmx mdrun= needs =PLUMED_KERNEL= pointed at =libplumedKernel.so=.
The meson test =gromacs_mdrun= writes a two-atom topology, runs =grompp= and
=mdrun -nsteps 0 -plumed=, and checks the printed bias against =rgpot-lj=.
The box is 4 nm so the neighbour list cutoff is shorter than half the cell.
Set =-Dwith_gromacs=enabled= and =-Dwith_plumed=enabled= to require the
binaries.
Auto skips the test when =gmx= or the PLUMED headers are absent.

** Public constructor

=rgpot_gromacs_potential= stores the GROMACS units once.
=rgpot_md_kj_per_ev= is
kJ/mol in one eV, 96.48533212331002, and =rgpot_md_nm_per_angstrom= is 0.1. A 1 eV well, an 8 Angstrom cutoff and a 1 Angstrom zero crossing are stored as =U0= from =rgpot_md_kj_per_ev=, cutoff 0.8 nm and psi 0.1 nm. An empty engine path evaluates the shifted potential in process. A path is a library whose =rgpot_md_native_force= already speaks nanometres and kJ/mol;
the constructor converts the geometry and the result with the stored factors.
=rgpot_external_potential_energy_forces= and =rgpot_external_potential_free= are
the same calls as for LAMMPS.
The dimer is -0.3203213355 eV.
When =gmx= or the GROMACS headers are absent the engine comparison is skipped
and the log says so.

#+begin_src python
import numpy as np
import rgpot

pot = rgpot.rgpot_gromacs_potential(1.0, 8.0, 1.0)
energy, forces, variance = pot(
    np.array([[0.0, 0.0, 0.0], [1.5, 0.0, 0.0]]),
    [1, 1],
    np.diag([20.0, 20.0, 20.0]),
)
#+end_src

#+begin_src cpp
rgpot::ExternalLjConfig cfg;
cfg.u0 = 1.0;
cfg.cutoff = 8.0;
cfg.psi = 1.0;
auto pot = rgpot::rgpot_gromacs_potential(cfg);
#+end_src
