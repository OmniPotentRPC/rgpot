* ASE calculators

=rgpot.ase= is an optional extra (=pip install 'rgpot[ase]'=, ASE 3.23 or
newer).
=import rgpot= does not import ASE.
The in-process calculator evaluates a bound potential in this process.
The Cap'n Proto calculator talks to =potserv=.

ASE itself is described by Hjorth Larsen et al., J. Phys.: Condens.
Matter 29, 273002 (2017), doi:10.1088/1361-648X/aa680e.

** In process

#+begin_src python
from ase import Atoms
from ase.optimize import BFGS
from rgpot.ase import RgpotCalculator

atoms = Atoms("Al7", positions=[[0, 0, 0]] * 7, cell=[30, 30, 30])
atoms.calc = RgpotCalculator("eam_al")
BFGS(atoms, logfile=None).run(fmax=0.05)
print(atoms.get_potential_energy())
#+end_src

=RgpotCalculator= accepts an rgpot potential object or a kind string (=lj=,
=eam_al=, and the other bound names) plus that potential's parameters.
=implemented_properties= is =energy=, =free_energy=, and =forces=.
=stress= is added only when the potential's caps report it.
There is no per-atom =energies= flag on those caps, so the calculator does not
invent one.
=free_energy= equals =energy=: these potentials have no electronic entropy term.

Energies are eV, forces are eV/Angstrom, and stress is eV/Angstrom^3 in ASE
Voigt order (xx, yy, zz, yz, xz, xy) with the ASE sign.

The bound kernels are fully periodic.
A structure with =pbc= false is a cluster: the calculator ignores its cell and
passes a cubic box whose side is at least 100 Angstrom and at least the cluster
extent plus twice the kernel cutoff.
A mixed =pbc= raises =ValueError= and names the non-periodic axes.

=calculate_many= evaluates a list of =Atoms= in one batch.
The default properties are energy and forces.
Pass =attach=True= to store a =SinglePointCalculator= on each structure.
The inputs are not modified.
=get_hessian= raises =NotImplementedError=.
No bound potential has an analytic Hessian.

** RPC calculator

=RgpotRpcCalculator= is the Cap'n Proto calculator.
One connection belongs to one calculator.
A second thread that enters =calculate= while the first still holds the
connection gets =RuntimeError=.
The old import =ase_calculator.RgpotCalculator= warns and re-exports this class.

** Annealing helper

=AnnealRunner= calls =anneal.global_optimize= and writes the best geometry back
onto the atoms.
It is not an =ase.optimize.Optimizer=.
=AnnealOptimizer= is the old name and warns on construction.
