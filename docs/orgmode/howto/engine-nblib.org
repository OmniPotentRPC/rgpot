* GROMACS nblib

GROMACS ships a small C++ library, nblib, that builds a topology and evaluates
its nonbonded and listed forces without running =mdrun=.
rgpot can load it in process.
The optional backend builds as =libnblib_engine= with
=-Dwith_nblib=enabled=. It provides an engine-generic MD session that steps
the topology with nblib and reads its state back.

GROMACS is linked into =librgpot_nblib= only.
=librgpot= loads that library with =dlopen=, so a program that links rgpot does
not link GROMACS.

** Build

nblib is an optional part of GROMACS.
It needs the installed nblib and legacy headers and shared libraries, and a
double-precision build, because a consumer that does not define =GMX_DOUBLE=
disagrees with the library about the size of =real=.
=engines/nblib/build_gromacs.sh= builds the pinned release (2025.5, checked
against the tarball's sha256) into a prefix:

#+attr_rgpot: skip builds GROMACS, several minutes
#+begin_src bash
engines/nblib/build_gromacs.sh "$HOME/gmx/install"
meson setup build -Dwith_nblib=enabled -Dnblib_prefix="$HOME/gmx/install"
meson compile -C build
#+end_src

=nblib_prefix= is the GROMACS install prefix.
The library found there is =libnblib_gmx=.
=nblib_gmx= names a double-precision =gmx= for the reference tests; empty uses
=gmx_d= under the prefix, then on =PATH=.
Without one the =mdrun -rerun= test skips and the rest run.

The meson tests are =nblib_api= (probes, potential, session, hooks, boundary,
projection, thermostat, walls and the =NblibPot= frontend) and
=nblib_gmx_rerun= (energies, forces and virial against =gmx_d mdrun -rerun=).

** Topology text

A topology is a line-oriented text.
Blank lines and everything after =#= are ignored.
An error names the line.

| Line | Meaning |
|------+---------|
| =nblib 1= | format version, first line |
| =cutoff <nm>= | nonbonded cutoff |
| =coulomb none= or =coulomb cutoff= | no Coulomb, or GROMACS' reaction field with \(\epsilon_{rf}=1\) |
| =atomtype <name> <mass> <c6> <c12>= | amu; kJ mol^-1 nm^6 and nm^12 |
| =pair <A> <B> <c6> <c12>= | explicit cross term; otherwise geometric combination |
| =molecule <name> <count>= ... =end= | a molecule, repeated =count= times |

Inside a molecule:

| Line | Parameters |
|------+------------|
| =atom <name> <type> <charge>= | charge in e |
| =exclude <a> <b>= | atom names or indices |
| =bond harmonic= or =g96 <a> <b> <k> <r0>= | kJ mol^-1 nm^-2 (g96: nm^-4), nm |
| =bond morse <a> <b> <depth> <beta> <r0>= | kJ/mol, nm^-1, nm |
| =angle harmonic= or =g96 <a> <b> <c> <k> <theta0>= | kJ mol^-1 rad^-2, degrees |
| =dihedral proper <a> <b> <c> <d> <phi0> <k> <mult>= | degrees, kJ/mol |
| =dihedral improper <a> <b> <c> <d> <phi0> <k>= | degrees, kJ mol^-1 rad^-2 |
| =dihedral rb <a> <b> <c> <d> <c0> ... <c5>= | kJ/mol |
| =pair14 <a> <b> <c6> <c12>= | 1-4 Lennard-Jones |

The argon box of the tests is

#+attr_rgpot: skip topology text read by NblibPot, not code
#+begin_src text
nblib 1
cutoff 0.7
coulomb none
atomtype Ar 39.948 0.0061551187151104025 9.508454572106801e-06
molecule argon 108
  atom Ar Ar 0.0
end
#+end_src

** MD session

The session uses the canonical =rgpot_md_session_*= C ABI in
=CppCore/rgpot/ExternalPot/external_potentials.h=. nblib and OpenMM export the
same vtable ABI from separate engine libraries. Use
=rgpot_md_session_create("nblib", ..., topology, ..., ...)=; its loader uses
the generic engine environment-variable lookup before its default library
name.

| Call | Purpose |
|------+---------|
| =rgpot_md_session_create=, =destroy= | a session from engine-defined text and common integration controls |
| =rgpot_md_session_set_periodic_box=, =set_positions=, =set_velocities= | state in |
| =rgpot_md_session_initialize= | evaluate the first forces |
| =rgpot_md_session_get_state= | positions, velocities, forces and energies |
| =rgpot_md_session_step_nve= | plain NVE steps |
| =rgpot_md_session_step_langevin= | Langevin steps on a hyperplane, with optional planar hard walls |

The units at the boundary are Angstrom, eV, ps and amu.
=get_state= reports the force of the potential at the positions.
Positions are never folded into the box.
Velocities are \(v(t)\) at the time of the positions; nblib's leap-frog
integrator keeps them half a step away, and the session converts, so a plain
step is the velocity Verlet map and =set_velocities= with \(-v\) reverses a
trajectory.

=step_langevin= restricts the dynamics to the plane \(n\cdot(x-p)=0\).
Positions are projected onto it, velocities and forces in the mass-weighted
metric.
Once per step the velocities take an Ornstein-Uhlenbeck update at the =k_t=
and =friction= supplied to =create=, and are projected again.
A step that ends outside a wall \(n_w\cdot x\le o_w\) is undone, and the
velocity component along the wall normal is reflected in the mass-weighted
metric, which conserves the kinetic energy.

** nblib behaviours the backend works around

- nblib 2025.5 integrates with leap-frog only, in a rectangular box, without
  constraints.
  Water is therefore flexible: a bond and an angle replace SETTLE.
- The nonbonded Lennard-Jones is potential-shifted and the Coulomb cut-off is
  reaction field with \(\epsilon_{rf}=1\).
  =grompp= warns that \(\epsilon_{rf}=\epsilon_r\); the reference test passes
  =-maxwarn 1= for that warning only.
- The CPU nonbonded calculator adds the energies of each call to those of the
  last; the library takes the difference, and recreates the calculator every
  256 calls so the running sum stays small.
- The improper-dihedral forces of nblib have the wrong sign.
  The library puts impropers in a separate calculator and subtracts its forces.
- The listed virial assumes whole molecules; the library unwraps each molecule
  sequentially, so a chain longer than half the box is right.

** Checks

Every number in =nblib_gmx_rerun= comes from =gmx_d mdrun -rerun= on a =.gro=
frame and a GROMACS topology that says what the nblib topology says, and is
compared with the library on the same coordinates.
Forces agree to \(2^{-30}\) of the largest force; the energy and the virial to
the six printed digits.
The systems are an argon box, an SPC/E water box with flexible bonds, and a
chain with every bonded form above.
=nblib_api= checks energy conservation of NVE runs, time reversal, continuity
across the box, the hooks, the boundary callback, the projection, the
thermostat's temperature and seed reproducibility, and the walls.
