program test_cuh2()

Physics checks for the CuH2 embedded-atom gather kernel, run from pure Fortran so a failure points at the kernel rather than the bindings.

Checked: translational invariance of the energy, vanishing net force, invariance under a relabelling of the atoms, and agreement between the analytic forces and a central difference of the energy.

The finite-difference check is the acceptance gate for the gather rearrangement. An embedding force attributed to the wrong end of a pair leaves the energy exactly right, keeps the net force at zero, and shows up only here.

The reordering check is the gate for the species dispatch: energies and forces are compared against a run with the atom list reversed, so H no longer occupies the trailing indices.

#define RGPOT_SC_API

Sutton-Chen potential.

Sutton and Chen, Philosophical Magazine Letters 61, 139 (1990):

E = epsilon * [ 1/2 sum_i sum_{j != i} (a / r_ij)^n

  • c * sum_i sqrt(rho_i) ] rho_i = sum_{j != i} (a / r_ij)^m

Gold and platinum use n = 10, m = 8, c = 34.408. The cluster references are in the reduced units epsilon = 1, a = 1 written on the first line of the Doye and Wales point files (doye.chem.ox.ac.uk/jon/structures/SC/10-8/). Those files are the deposited Pt38 Oh and Pt75 D5h geometries. Doye and Wales attribute n, m and c to the 1990 paper. Physical epsilon and a for both metals are the presets in SuttonChenScales.hpp.

optbench’s globalopt Lennard-Jones problems truncate at cutoff 40 in the coordinate unit (problems/globalopt/lj75.toml). The same truncation, with no energy shift, is the default. cutoff <= 0 keeps every pair. On the deposited clusters every pair sits inside r = 3, so the default and the full sum agree past the published digits.
