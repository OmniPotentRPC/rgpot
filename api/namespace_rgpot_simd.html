Detailed Documentation¶

Global Functions¶

const char* chosen_target_name()

Name of the target selected for this process (“scalar”, “sse2”, “sse4”, “avx2”, “avx3”, “avx3_zen4”, “neon”, “sve”, “sve2”, “sve_256”, “rvv”, “emu128”). RGPOT_SIMD is read once, inside the call_once that caches the choice.

void set_target_for_test(const char* name)

Test hook. “scalar” forces the portable kernel. A known target the CPU cannot run falls back to the best target it can run. On x86-64 that is at least SSE2. An unknown name is ignored. Not for production paths: Highway’s chosen target is process-wide.

int runnable_target_count()

Targets this CPU can execute, scalar first. A name that is absent was not exercised.

double lj_force_span(const PairView& view, const LjParams& params, double* F, double strain[6], std::size_t begin, std::size_t end)

Same kernel as lj_force, limited to atoms in [begin, end). One thread keeps calling lj_force so the pair order does not change.

void fma_array(const double* a, const double* b, const double* c, double* out, std::size_t n)

Test hook. Each output is a*b+c rounded once, on the selected target.

void fold_orthorhombic(double* x, double* y, double* z, std::size_t n, double w0, double w1, double w2, double i0, double i1, double i2)

In-place orthorhombic minimum image, one component array per axis. inv == 0 leaves that axis unfolded.

double exact_fma(double a, double b, double c)

a*b+c with one rounding, the same bits as a hardware fused multiply-add. Normals in range use a Dekker product and a round-to-odd sum (Boldo and Melquiond). Inputs outside that range and subnormal results use std::fma.

double mul_add(double a, double b, double c)

a*b+c, one rounding. A hardware instruction when this translation unit has one, or when fma_hw_active(). Otherwise fma_quick.

double r2_of(double dx, double dy, double dz)

dx^2 + dy^2 + dz^2. The first square is a multiply. The two sums fuse.

double exp(double x)

Scalar exp. Cody-Waite reduction by a split ln(2), then the fdlibm degree-5 polynomial. The large-argument scale and each polynomial product-sum are one rounding. Overflow returns +inf, underflow returns 0, a NaN returns a NaN, and exp(-0) is +1. Vector targets replay these operations per lane.

double exp_fixed(double x)

e^x with the same bits on every instruction set and C library. Within 1.24 ulp for normal results (see docs/orgmode/reference/simd_exp.org).

void exp_fixed_n(const double* x, double* out, std::size_t n)

out[i] = exp_fixed(x[i]) for i < n. Vectorised and dispatched on the CPU at run time; every variant returns the bits of exp_fixed.

void fill_view(CachedPairs& out, const double* R, std::size_t n, const double* box, const PairSpec& opt, nlist::Mode mode = nlist::Mode::Auto, nlist::Neighbours* reuse = nullptr)

Build a half-list for the dispatched pair kernels. Candidates come from the shared neighbour layer. reuse keeps the Verlet list across calls. Several threads walk disjoint atoms and the rows are sorted, so the list does not depend on which thread found a pair. fold is the orthorhombic round, with a zero inverse on an axis the options leave unfolded.
