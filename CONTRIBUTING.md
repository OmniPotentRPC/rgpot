# Contributing to rgpot

The contributing guide is in the documentation, at [rgpot.rgoswami.me][guide].
The Org sources of those pages live under `docs/orgmode/contributing/`.

- Post questions, bug reports and feature ideas on the [issue tracker][issues].
- Report security vulnerabilities privately, following [SECURITY.md][security].
- Do not open a public issue for a security report.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Set up the `pixi` development environment with the [Developer Guide][dev].

[guide]: https://rgpot.rgoswami.me/contributing/index.html
[issues]: https://github.com/OmniPotentRPC/rgpot/issues
[security]: SECURITY.md
[dev]: docs/orgmode/contributing/developer/index.org
