* rgpot-core

Core Rust library for [[https://github.com/OmniPotentRPC/rgpot][rgpot]]:
RPC-based distributed potential energy surface calculations.

** Overview

~rgpot-core~ follows the [[https://docs.metatensor.org/][metatensor]]
architecture pattern: a Rust core that defines fundamental types, exposed via a
stable C ABI (auto-generated by
[[https://github.com/mozilla/cbindgen][cbindgen]]), with hand-written C++ RAII
wrappers on top.

Data exchange uses the [[https://github.com/dmlc/dlpack][DLPack]] tensor
protocol for device-agnostic interoperability (CPU, CUDA, ROCm).

** Features

| Feature | Description |
|---------+-------------|
| /(default)/ | Core types, DLPack tensor helpers, callback-based potential dispatch |
| =schema= | Generated bindings for the shared =PotentialConfig=, =ForceInput=, and =PotentialResult= carriers |
| =profile= | Prefix-generic in-process loader with one persistent backend session |
| =rpc= | Cap'n Proto RPC client and server for distributed calculations |
| =cache= | /(planned)/ Result caching layer |

** Quick Start

# [[[cog import rgpot_version as v; cog.outl(v.readme_org())]]]
#+begin_src toml
[dependencies]
rgpot-core = "3.6.0"
#+end_src
# [[[end]]]

Enable the in-process profile loader for backends such as =nwchemc= and =cpmdc=:

# [[[cog import rgpot_version as v; cog.outl(v.readme_org("profile"))]]]
#+begin_src toml
[dependencies]
rgpot-core = { version = "3.6.0", features = ["profile"] }
#+end_src
# [[[end]]]

Enable the RPC client and server:

# [[[cog import rgpot_version as v; cog.outl(v.readme_org("rpc"))]]]
#+begin_src toml
[dependencies]
rgpot-core = { version = "3.6.0", features = ["rpc"] }
#+end_src
# [[[end]]]
