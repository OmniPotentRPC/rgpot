#+TITLE: rust-core nanobind template
#+OPTIONS: toc:nil todo:nil num:nil author:nil title:nil

* Copy this directory

The template is a scikit-build-core project.
It builds a Rust crate as a =staticlib= with Corrosion, then a nanobind
module =rust_core_demo._core=.
The importable package lives at =python/rust_core_demo/=.
Python never calls a symbol that the C ABI does not export.

Replace these three names when you copy the directory:

- crate name =rust_core_demo= in =examples/rust-core-demo/Cargo.toml=
- =MANIFEST_PATH= and =CRATES= in =CMakeLists.txt=
- the =extern "C"= entry declared in =src/ext.cpp=

Keep =nanobind_add_module(_core FREE_THREADED STABLE_ABI NB_STATIC ...)=.
Keep =nanobind_add_stub=.
Keep =wheel.py-api = "cp312"= so GIL builds are tagged =cp312-abi3=.
Free-threaded interpreters ignore that classic abi3 tag and emit
=cp314-cp314t= or =cp315-cp315t=.

* Steps

1. Install a C++17 compiler, CMake, Ninja, and Rust (stable).
2. Install nanobind >= 3.1 and scikit-build-core >= 1.1.
3. From this directory run =python -m pip install .=.
4. Import =rust_core_demo=.
   On a free-threaded build, =sys._is_gil_enabled()= is =False= (F1).
5. Regenerate the stub with
   =python -m nanobind.stubgen -m rust_core_demo._core= and commit it
   at =python/rust_core_demo/_core.pyi=, next to =py.typed=.

The cibuildwheel table builds =cp310-*=, =cp311-*=, =cp312-*=,
=cp314t-*=, and =cp315t-*=.
Platforms are manylinux_2_28 (x86_64 and aarch64), macOS 14 arm64, and
Windows AMD64.
There is no musllinux build.
=abi3audit= runs as the cibuildwheel default on the abi3 wheel.

* Thread safety

The Rust function is =extern "C"= and wraps its body in
=std::panic::catch_unwind= (F9).
The C++ wrapper checks rank with =rgbind::check_f64_rank= before it
reads an extent, then checks the length with =rgbind::check_f64_1d=.
It drops the GIL for the call (F4, F6).
Inputs are float64, C contiguous, and CPU, with =.noconvert()=.
=rgbind::install_policy= registers the translators from the vendored
header =include/rgbind/rgbind.hpp=.
The link line uses hidden visibility, =-Wl,--exclude-libs,ALL= on Linux,
an export list on macOS, and a =.def= file on Windows.
Each of those keeps only =PyInit__core= (F9).
Sub-interpreters are unsupported.
Compile with =-ffp-contract=off=.

This demo has no mutable session, so it does not take an F3 claim.
A package that adds one uses =rgbind::Claim= from that same header.

* Vendored header

=include/rgbind/rgbind.hpp= is a byte copy of
=bind/include/rgbind/rgbind.hpp= in OmniPotentRPC/rgpot.
The reusable workflow =py-rgbind-sync= takes the vendored path and an
rgpot ref, fetches that header, and fails on any byte difference.
=py-ci= calls it with the commit being built.
After you edit the upstream header, copy it here again before merging.

* Free-threaded CI

=py-ci= calls =py-wheels=, =py-freethreading=, =py-tsan=, and
=py-typing= on this directory as well as on =bind/=.
A package sets three inputs: =import-names: rust_core_demo._core=,
=stub-dir: python=, and
=typecheck-paths: python/rust_core_demo examples=.
=py.typed= lives in the package directory, not at the wheel root.
T2 builds the extension with =-fsanitize=thread= against
=ghcr.io/nascheme/numpy-tsan:3.14t@sha256:f6dd658f1a155be35e27b182cac97c2a77c4b2d62bacb81753beaba725978149=.
Pass =-DRUST_CORE_TSAN=ON= to build the staticlib with a nightly rustc,
=-Zsanitizer=thread=, =-Zbuild-std=std,panic_abort=, and an explicit
target triple (=x86_64-unknown-linux-gnu= or =aarch64-unknown-linux-gnu=).
The =rust-toolchain= input defaults to =nightly-2026-01-20= and the job
passes that name to CMake as =-DRust_TOOLCHAIN=.
It installs that toolchain with =rust-src= and fails unless the clang
and rustc LLVM majors match.
After the build it counts =__tsan_func_entry= in =librust_core_demo.a=
and fails if the count is zero.
That nightly is LLVM 21, which is the major in the image above.
The CPython suppression file is pinned to
=bf397e272c2bee639c3ba0208c221f7dd9447bb6=, not the floating 3.14 branch.
A second pytest pass uses =pytest-run-parallel --parallel-threads=4
--iterations=5=.

* Demo crate

=examples/rust-core-demo= is a twenty-line =extern "C" fn dot=.
The sum walks indices in order.
CI builds it into a wheel on cp312 (=cp312-abi3=) and cp314t
(=cp314-cp314t=).
