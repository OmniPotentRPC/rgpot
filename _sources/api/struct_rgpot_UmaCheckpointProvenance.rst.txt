Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Where the weights of a ``.pt2`` came from, and their digest.

Built from the package metadata, as UmaContract is. Every field is optional: packages exported before these keys report all of them absent and load as before. ``scripts/export_uma_aoti.py`` writes

* ``checkpoint_source`` : ``cli`` (``--checkpoint``), ``env`` (``RGPOT_UMA_CHECKPOINT``) or ``hf`` (downloaded for ``--model``);

* ``checkpoint_path`` : the local file, for ``cli`` and ``env``;

* ``checkpoint_hf_repo``, ``checkpoint_hf_filename`` and ``checkpoint_hf_revision`` (the 40-digit commit the file was served from), for ``hf``;

* ``checkpoint_sha256`` : SHA-256 of the checkpoint file the exporter loaded, 64 lowercase hexadecimal digits.

The digest names the weights, not the ``.pt2``; the engine ABI's ``rgpot_engine_model_digest`` hashes the package file itself.
