Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Stillinger-Weber silicon (PotType::SWSi). Epsilon is eOn's 2.16826 \* 1.06767385 = 2.3149945 eV, not the published 2.16723920 eV of PotType::SWSi1985. Their ratio is 1.068176741337. The factor 1.06767385 is untraced; see :ref:`rgpot_sw.f90 <doxid-rgpot__sw_8f90_source>`.
