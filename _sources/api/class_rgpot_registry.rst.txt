Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Static registry for instance tracking and statistics.

The registry counts active instances of a derived potential class and how many times those instances have been evaluated.

Fields
------

.. index:: pair: variable; count
.. _doxid-classrgpot_1_1registry_1ac4bac5e107803e7b48bb0eab8b0978eb:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	static std::atomic<size_t> count

Total number of active instances.

Active-instance and force-call counters. Both are atomic so a batch worker can construct or evaluate a potential while another worker does the same (F2). There is no process-global list of instances: each DSO that includes this header would otherwise keep its own ``head``, and the destructor in librgpot would write through a node freed by the Python extension.
