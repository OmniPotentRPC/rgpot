	const :ref:`NeighborList<doxid-structrgpot_1_1nlist_1_1_neighbor_list>`& orderedPairs(const double* positions, const double* box, std::size_t n, double cutoff, :ref:`NeighborList<doxid-structrgpot_1_1nlist_1_1_neighbor_list>`* cache)

:ref:`Pairs <doxid-structrgpot_1_1nlist_1_1_pairs>` with r < cutoff + skin, ordered as the 27-cell walk. The reference is valid until the next call on this thread that passes a null cache. On a hit, the cached pairs are returned as stored.

.. index:: pair: function; build
.. _doxid-_neighbour_list_8cc_1a3641a03aa5c89a7f06e3f4a10f875e3f:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	void build(:ref:`Table<doxid-structrgpot_1_1nlist_1_1_table>`& table, const double* positions, std::size_t n, const double* box9, const :ref:`Query<doxid-structrgpot_1_1nlist_1_1_query>`& query)

Fill ``table`` from ``query``. The table holds every pair. A caller that must not store the list uses :ref:`Walk <doxid-classrgpot_1_1nlist_1_1_walk>`. Throws :ref:`Error <doxid-classrgpot_1_1nlist_1_1_error>` before clearing ``table`` when the geometry is rejected. Two builds on different tables may run at the same time. They share no mutable global. A build of at least 8192 atoms may start an OpenMP team. A smaller build stays on the calling thread.

.. index:: pair: function; buildByAtom
.. _doxid-_neighbour_list_8cc_1a1b061e6d56f25a6d6692411e283cfe68:

	void buildByAtom(:ref:`Table<doxid-structrgpot_1_1nlist_1_1_table>`& table, const double* positions, std::size_t n, const double* box9, const :ref:`Query<doxid-structrgpot_1_1nlist_1_1_query>`& query)

The same pairs as ``build``, gathered one atom at a time. A CUDA, HIP or Kokkos launch gives one thread one atom and runs this walk. The host ``build`` remains the source of truth.

.. index:: pair: function; updateCells
.. _doxid-_neighbour_list_8hpp_1a03b84bcc3c0939efcb7f0bd31bfc6a87:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	void updateCells(:ref:`Neighbours<doxid-classrgpot_1_1nlist_1_1_neighbours>`& cells, const double* positions, std::size_t n, const double* box9, double cutoff, double skin, :ref:`Image<doxid-struct_image>` image, Mode mode, const std::array<bool, 3>& periodic)

Bind ``cells`` to this geometry. ``cutoff`` is the pair cutoff and ``skin`` is the Verlet buffer the kernels drop inside the cutoff. ``image`` is Round for an orthorhombic cell, Half after coordinates have been wrapped, and General for a sheared cell. ``mode`` stores the index when it fits and streams otherwise, unless the caller asks.

Thread count from OMP_NUM_THREADS. Unset, empty, or a non-positive value is one thread, so a call that does not ask for threads matches the serial pair order.

	bool withinSkin(const double* reference, const double* current, std::size_t n, double skin)

True when every atom has moved by at most half of ``skin`` from ``reference``. Skin 0 is true only when the coordinates match. The same test decides ``Builder::update`` 's reused flag.
