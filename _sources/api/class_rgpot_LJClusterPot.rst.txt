Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Shifted 12-6 Lennard-Jones for isolated clusters.

Every pair within the cutoff contributes, with vectors taken straight from the coordinates: periodicity is off, so the walk never folds a separation into the cell. A cluster whose bounding box fits inside the cutoff, and whose call is not a stream, walks ``i < j`` in SoA form. Every other call runs the pair term on the shared cell walk. A stream copies no pair index. A nonzero switch width skips the direct walk, which has no switch. A degenerate input cell is replaced by a 1e6 Angstrom cube.

Same pair kernel as ``:ref:`LJPot <doxid-classrgpot_1_1_l_j_pot>``` with the minimum image convention switched off, so an input cell never folds pair vectors.

.. ref-code-block:: cpp

	virtual uint64_t paramsKey() const

Fingerprint of the potential's parameter set.

Mixed into the result-cache key so results never cross parameter sets. Implementations hash their config field by field (see :ref:`ParamHash.hpp <doxid-_param_hash_8hpp_source>`) plus a kernel-version salt that changes whenever the numerics change. The default (0) suits parameter-free potentials whose numerics never changed.
