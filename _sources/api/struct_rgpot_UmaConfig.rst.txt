Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

UMA / OMol calculator configuration.

model_path is an AOTInductor package (.pt2) produced by scripts/export_uma_aoti.py. Neighbor lists are built with vesin and passed as tensors; the compiled graph does not call fairchem.
