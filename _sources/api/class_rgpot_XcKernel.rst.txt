	int applyFxc(const :ref:`XcGrid<doxid-structrgpot_1_1_xc_grid>`& grid, const std::map<std::string, const double*>& ground, const double* dm, double* vxc) const

XC fxc on one AO density via this kernel. Ground-state scal holds weights, Libxc arrays, and (GGA) grad_rho_a\_\*. Perturbed rho/grad names (``rho_a_p1``, ``grad_rho_a_p1_*``) are built from dm. Accumulates into vxc (nao\*nao, +=).

TDA sigma with host Coulomb: v1 = vj + 0.5 \* applyFxc(dm(z)). vj is the host J matrix on the transition DM (nao\*nao).

	static void transitionDm(const :ref:`XcMo<doxid-structrgpot_1_1_xc_mo>`& mo, const double* z, double occ, double* dm)

dm = einsum('qo,ov,pv->pq', Co\*occ, z, Cv). Matches lib.einsum path ('qo,xov->vxq' then 'vxq,pv->xpq') used by TDA.gen_vind.

.. index:: pair: function; projectOv

	static void projectOv(const :ref:`XcMo<doxid-structrgpot_1_1_xc_mo>`& mo, const double* Vao, double* ov)

ov = einsum('pv,pq,qo->ov', Cv, V, Co) == Co^T @ (V^T @ Cv). Matches lib.einsum path ('pv,xpq->vxq' then 'vxq,qo->xov').
