Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Candidate pairs around one configuration.

A stored list is reused while every atom has moved by at most half the skin, and the cell, the count and the spec are unchanged. Skin 0 reuses the list only when the coordinates and the cell match.

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	template <typename Fn>
	void forDirected(std::int64_t begin, std::int64_t end, Fn&& fn) const

Directed pairs for atoms in ``[begin, end)``. ``dx`` is ``r_i - r_j`` after the selected image. ``r2`` is the squared length of that vector. Candidates lie inside the cutoff plus the skin; the caller drops the rest. In stored mode the partners of each atom are in increasing index order.

.. index:: pair: function; forHalf
.. _doxid-classrgpot_1_1nlist_1_1_neighbours_1a7b66f85f00aa7b28829e9a4802cc5531:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	template <typename Fn>
	void forHalf(std::int64_t begin, std::int64_t end, Fn&& fn) const

The pairs of ``forDirected`` with ``j > i`` only. Geometry for ``j <= i`` is not computed. A serial two-pass potential uses this so each unordered pair is visited once per pass.

.. index:: pair: function; forCellTeam

.. ref-code-block:: cpp

	template <typename Fn>
	void forCellTeam(bool half, int nthreads, Fn&& fn) const

One walk of the directed pairs, split by cell across ``nthreads``. The bins are built once and shared. ``fn(thread, i, j, dx, dy, dz, r2)``. A thread owns each cell, so a pair is visited once.
