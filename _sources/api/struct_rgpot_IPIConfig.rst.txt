Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Where the driver connects, and how long one force call may wait.

address is ``unix:/absolute/path``, ``unix:<name>`` (binds ``/tmp/ipi_<name>``, the i-PI default prefix), ``tcp:<host>:<port>``, or ``tcp:<port>`` (host 127.0.0.1). Port 0 asks the kernel for a free port; endpoint() reports the port that was chosen.
