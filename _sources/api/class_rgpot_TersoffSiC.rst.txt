Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Tersoff potential for silicon, carbon, and silicon-carbide.

Atomic numbers are 14 and 6. One call evaluates a whole configuration. ``energyAndGradientBatch`` evaluates many configurations that share a cell and a species list.

	virtual uint64_t paramsKey() const

Fingerprint of the potential's parameter set.

Mixed into the result-cache key so results never cross parameter sets. Implementations hash their config field by field (see :ref:`ParamHash.hpp <doxid-_param_hash_8hpp_source>`) plus a kernel-version salt that changes whenever the numerics change. The default (0) suits parameter-free potentials whose numerics never changed.

	void setHeldSkin(double skin)

Keep one Verlet list across forceImpl calls.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- skin

		- Extra search distance, Angstrom. Zero, the default, rebuilds the pairs on every call. A positive skin reuses them until an atom has moved by more than skin/2 since the last build, or the cell or the atom count changes. The instance then reports :ref:`Reentrancy::PerInstance <doxid-namespacergpot_1afc52f666d5e44be6f4cc73b2009ed9bba638926405e39d8cd5227b49fa3156e1a>`.

Energy and dE/dx for one configuration.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- positions

		- Row-major coordinates, Angstrom.

	*
		- atomic_numbers

		- Length n_atoms. 14 is silicon, 6 is carbon.

	*
		- box

		- Row-major cell, Angstrom. Periodic in every direction.

	*
		- n_atoms

		- Atom count.

	*
		- energy

		- Receives the energy, eV.

	*
		- gradient

		- Receives dE/dx, eV/Angstrom. The force is its negation.

	*
		- neighbors

		- Optional Verlet list. Null rebuilds the pairs on every call. A list is reused while each atom has moved by at most half its skin and the cell is unchanged.
