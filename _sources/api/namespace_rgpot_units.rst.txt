Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Physical constants and unit conversion factors for atomistic potentials.

All values are CODATA 2018 recommended values. rgpot's native unit system: energy = eV, length = Angstrom, force = eV/Angstrom.
