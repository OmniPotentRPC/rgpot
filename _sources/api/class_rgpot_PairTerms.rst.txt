Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

``Width`` doubles for each pair of a first pass, in visit order.

A pass keeps pairs until the room that ``record`` made is full. Past it ``push`` and ``next`` return null and the second pass computes its terms again. Nothing is allocated during a pass, so a pair loop holds no call; the next ``record`` makes room for every pair the last pass saw, up to ``limit()``. The block is kept from one evaluation to the next, so a potential that outlives a call refills the same memory.
