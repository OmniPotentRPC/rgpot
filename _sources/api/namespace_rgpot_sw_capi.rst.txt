Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

C entry point for the Stillinger-Weber potential.

Only ``bind(c)`` names leave this library; the physics module exports no external symbols of its own that C could collide with. The ``_ws`` entry point keeps the neighbour table in the caller's workspace (:ref:`rgpot_workspace <doxid-namespacergpot__workspace>`), so each caller's neighbour table follows its own geometry; the entry point without a handle shares one module-level workspace and is process-serial.

	integer(c_int) function, public rgpot_sw_force(integer(c_int), intent(in), value natoms, real(c_double), dimension(3, natoms), intent(in) positions, real(c_double), dimension(3, 3), intent(in) cell, real(c_double), dimension(3, natoms), intent(out) forces, real(c_double), intent(out) energy)

Evaluate Stillinger-Weber forces and energy.

``positions`` and ``forces`` are ``3 * natoms`` doubles, x/y/z interleaved; ``cell`` is nine doubles, row-major, one cell vector per row. Returns zero on success, non-zero on failure with the message available through ``rgpot_fortran_last_error``.

	integer(c_int) function, public rgpot_sw_force_ws(type(c_ptr), value handle, integer(c_int), intent(in), value natoms, real(c_double), dimension(3, natoms), intent(in) positions, real(c_double), dimension(3, 3), intent(in) cell, real(c_double), dimension(3, natoms), intent(out) forces, real(c_double), intent(out) energy, real(c_double), dimension(6), intent(out), optional strain)

Evaluate Stillinger-Weber forces, energy and strain derivative in a per-caller workspace.

``positions`` and ``forces`` are ``3 * natoms`` doubles, x/y/z interleaved; ``cell`` is nine doubles, row-major, one cell vector per row. ``strain`` is six doubles, dE/dε in eV in the order of :ref:`stress.hpp <doxid-stress_8hpp_source>`; a NULL ``strain`` skips the virial and its per-atom array. Returns zero on success, non-zero on failure with the message available through ``rgpot_fortran_workspace_error``. ``handle`` is a workspace from ``rgpot_fortran_workspace_new``; a NULL handle returns -1.
