Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Concurrency and evaluation capabilities, the engine-side image of rgpot's PotCaps. ``size`` is sizeof(RgpotEngineCaps) on the host; the engine fills the fields that fit and sets ``size`` to the size it wrote. reentrancy: 0 one instance may be called from many threads, 1 one instance per thread, 2 every evaluation in the process is serialized.
