	double skin = 1.0

Verlet skin of the potential's own pair list, in the length unit of the table. forceImpl keeps the list while every atom stays within half of it (:ref:`nlist::Neighbours <doxid-classrgpot_1_1nlist_1_1_neighbours>`). 0 rebuilds it whenever an atom moves.
