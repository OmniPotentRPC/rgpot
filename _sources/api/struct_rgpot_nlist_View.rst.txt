struct rgpot::nlist::View
=========================

.. toctree::
	:hidden:

Non-owning view of a structure-of-arrays neighbour table. ``shift`` is empty or 3 entries per pair, ``vector`` is empty or 3, ``mask`` is one byte per pair (0xff for a pair list; bits 0..3 for a cluster of four). The spans are invalidated by the next rebuild of the table that owns them.
