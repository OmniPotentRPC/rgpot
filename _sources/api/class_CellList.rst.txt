Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

:ref:`CellList <doxid-class_cell_list>` is a helper class for :ref:`NeighborList <doxid-class_neighbor_list>` and QCPotential.

:ref:`CellList(atoms, rMax) <doxid-class_cell_list>` will put the atoms into cells of size minimum rMax (when used by the :ref:`NeighborList <doxid-class_neighbor_list>` class, rMax will be rCut + 2 \* drift). MakeNeighborLists(...) will generate neighbor lists and periodic images. GetNeighbors(...) will return all neighbors of point within a distance of rMax (useful for decoration in QC).
