Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Reusable pair list. A null list passed to orderedPairs rebuilds every call. skin is the extra search distance in Angstrom. The stored pairs are reused while every atom has moved by at most skin/2 and the cell is unchanged. skin 0 reuses the list only when the coordinates match.
