	bool fma_hw_active()

True when the hardware fused multiply-add may run: the CPU has FMA3 and the OS saves its registers (CPUID), glibc 2.33 or newer does not mask it, and RGPOT_FMA is not ``software``. Read once per process. The hardware instruction and the software path return the same bits, so this decides speed only.

	double exp_pow2(double m)

2^m for an integer-valued m in [-1022, 1023], built in the exponent field. m + 1023 lands in the low bits of the shifted sum.

	double exp_fixed_lane(double x)

The body every exp in rgpot runs, scalar or as a vector lane. Branch free: GCC and clang vectorise a loop over it. NaN propagates, +inf gives +inf and -inf gives +0.
