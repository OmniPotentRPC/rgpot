Overview
~~~~~~~~

Forcefield for water and platinum interactions. This forcefield is the A2 water-platinum potential invented by :ref:`Zhu <doxid-classforcefields_1_1_zhu_philpott_1zhu1994>` and Philpott". It includes the SPC/E+CCL potential for interaction between the
molecules of water. The SPC/E is a potential for constrained water. This
implementation includes restraints so it may be used without constraint (see
class SpceCcl).\n The potential uses Kong's rules to combine the Lennard-Jones
parameters of platinum with oxygen and hydrogen. A @ref combinationReview
"review of combination rules" including Kong's rule can be find on the web.

The system of unit used by the class is (eV, Angstrom, fs, e). :ref:`More...<details-classforcefields_1_1_zhu_philpott>`

Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Forcefield for water and platinum interactions. This forcefield is the A2 water-platinum potential invented by :ref:`Zhu <doxid-classforcefields_1_1_zhu_philpott_1zhu1994>` and Philpott". It includes the SPC/E+CCL potential for interaction between the
molecules of water. The SPC/E is a potential for constrained water. This
implementation includes restraints so it may be used without constraint (see
class SpceCcl).\n The potential uses Kong's rules to combine the Lennard-Jones
parameters of platinum with oxygen and hydrogen. A @ref combinationReview
"review of combination rules" including Kong's rule can be find on the web.

The system of unit used by the class is (eV, Angstrom, fs, e).

	void computeHH_O_Pt_(const int nWater, const int nPt, const double r[], double f[], double& energy, double const b[], bool const fixed[])

Compute water-platinum forcefield.

.. warning::

	The conductivity is simulated by interaction a mirror images of charges. The mirror surface is set at z=0, which should correspond to the location of the highest layer of platinum atoms.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- nWater

		- Number of molecules of water.

	*
		- nPt

		- Number of platinum atoms.

	*
		- r

		- Positions of the atoms.

	*
		- f

		- Forces on the atoms.

	*
		- energy

		- Potential energy.

	*
		- b

		- Periodic boundaries. Length: 3

	*
		- fixed

		- True for fixed atoms, false otherwise. The order of the atoms is all hydrogens (hydrogens belonging to the same molecule are next to each others), all oxygen, all platinum. The length of arrays *r* and *f* is :math:`3\times(3 \times nWater+nPt)`. The length of array *fixed* is :math:`3 \times nWater+nPt`. When *fixed* is provided the interaction between two fixed atoms may be skipped to speed up the calculation. The parameter is optional.

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	void computeHH_O_(const int nWater, const double r[], double f[], double& energy, double const b[], bool const fixed[])

Compute water-platinum interactions, call with water's positions only. This function is called with the coordinates of the atoms of water only. The positions of the platinum atoms must have been previously provided through function :ref:`setPlatinum() <doxid-classforcefields_1_1_zhu_philpott_1a85061840564b45f49c5928752f6d2013>`.

.. note::

	The function does not return the forces on platinum atoms as they as assumed to be fixed.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- nWater

		- Number of molecules of water.

	*
		- r

		- Positions of atoms in water.

	*
		- f

		- Forces on the atoms in water.

	*
		- energy

		- Potential energy.

	*
		- b

		- Periodic boundaries. Length: 3

	*
		- fixed

		- True for fixed atoms, false otherwise. The length of arrays *r* and *f* is :math:`9\times nWater`. The length of array *fixed* is :math:`3 \times nWater`.
