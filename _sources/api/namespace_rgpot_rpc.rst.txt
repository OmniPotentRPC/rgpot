Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

PotentialConfig.morse for a :ref:`MorsePot <doxid-classrgpot_1_1_morse_pot>` backend.

Name of the PotentialConfig arm a configure() call carries.

:ref:`MorsePot <doxid-classrgpot_1_1_morse_pot>` fixes its parameters at construction, so applying the morse arm builds a replacement pot. switch_width is not on the wire and carries over from the pot being replaced.

A peer built against a newer potentials-schema can send an arm this build does not know. which() then returns the raw discriminant, so the name comes from the compiled schema and an unknown arm is reported by its discriminant instead of indexing past the known ones.
