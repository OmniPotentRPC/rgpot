.. ref-code-block:: cpp

	double kEamThreadedTolerance = 1e-9

One OpenMP thread matches the direct pair loop bit for bit. Several threads each write the forces of their own atoms and add partial energies in thread-id order, so a fixed thread count repeats bit for bit. Energy and every force component stay within this relative tolerance of the one-thread value. A component whose one-thread magnitude is below 1 is compared on an absolute scale of the same size.

Create a potential from a Cap'n Proto flat-array message whose root struct is the engine's params arm in Potentials.capnp (UmaParams for the UMA engine). config points at config_len bytes (word-aligned capnp framing as produced by capnp::messageToFlatArray). Returns NULL on failure with a message in errbuf.

Energy + forces. transform (with transform_user) may be NULL; variance may be NULL. Returns 0 on success.

Strided-uniform batched evaluation: nSystems systems sharing one composition (atomicNrs, nAtoms). positions and forces hold 3\*nAtoms\*nSystems doubles with system stride 3\*nAtoms, energies nSystems doubles, variances likewise (may be NULL), boxes 9\*nSystems doubles with system stride 9. The transform is applied per system to the engine's scratch copy. For learning engines this call is also an incorporation boundary. A grouped variant (batches of uniform groups) is a separate symbol, never a flag here.

Monotone model-state counter for engines with internal mutable state. Increments on every refit / hyperparameter change / observation incorporation; host caches keyed on model output are valid only while the value is unchanged. Static engines omit the symbol (equivalent to a counter frozen at 0).

Register host callbacks. The struct is copied; ctx must outlive the potential or a subsequent call replacing it. Learning engines require an oracle before the first evaluation and fail create-time validation without one.

Runtime hint/tunable message: a Cap'n Proto flat-array whose root is the engine's hint arm on the shared Potentials.capnp wire (never a string-keyed channel). Also the host-initiated incorporation boundary for learning engines. The engine validates the resulting configuration as a whole before it takes effect; on failure the previous configuration stays active and errbuf holds the reason.

The loaded engine's identity.

Nonzero when the loaded engine serves a host built against ``stamp`` : equal major, equal layout revision, engine minor at least the host's. NULL returns 0.

Message of the last failed call on this instance (create errors go to its errbuf). Copies at most ``len - 1`` bytes and NUL-terminates; returns the full message length, 0 when there is none. Reading does not clear it; the next successful call does.

Short name of the backend the library serves, for example "uma".

Version of the engine build: "<name>/<rgpot version>". The pointer refers to static storage.

SHA-256 of the model file or archive the instance loaded, as 64 lowercase hexadecimal digits. Copies at most ``len - 1`` bytes and NUL-terminates; returns the digest length (64), or 0 when the backend has no model file or the file cannot be read. The digest is computed on first request and kept.

Backend thread settings: intra-op and inter-op worker threads of the engine's tensor runtime. A value below 1 leaves that setting alone. Process wide in effect, and the inter-op count can be set once before the first evaluation; a refused setting returns a positive code with the reason in last_error. Returns 0 on success and 3 for a backend without a tensor runtime. UmaParams and MetatomicParams carry the same two counts and apply them at create.

Change the total charge and spin multiplicity the next evaluations assume. The package was exported for one charge and spin; a mismatch is reported by the next force call. Returns 0 on success and 3 for a backend without a charge or spin.

Writes up to capacity declarations into opts and returns the total count (call with capacity 0 to size). Declarations may change after on_model_update; hosts re-query on that boundary.

Energy + forces. Returns 0 on success. variance may be NULL.

Pair energy, ``(dV/dr) / r``, and ``d2V/dr2`` for ``npairs`` squared distances. One call covers a whole pair list. Returns 0 on success.

Cluster energy and gradient. ``cutoff <= 0`` keeps every pair. Returns 0 on success, 1 on a bad argument.

Pair energy of each atom, added to both ends of every pair. The total energy is half the sum. Returns 0 on success.

Arithmetic-mean diameters. ``sigma`` has one entry per atom. ``cutoff <= 0`` keeps every pair. Energy is ``4 * sum (s^12 - s^6)``.

Species A is the first ``n_a`` atoms, species B the rest. ``eps`` and ``sig`` are ordered AA, AB, BB.

Drop the stored SCC wavefunction. The calculator stays, and the next force uses xtb's own guess.

Displacement guard in Angstrom. Zero or negative disables reuse.

1 when the last successful force reused the previous wavefunction.

Checked: translational invariance of the energy, vanishing net force, agreement between the analytic forces and a central difference of the energy, and rejection of an atomic number the potential does not cover. 	program test_tersoff()

Physics checks for the Tersoff gather kernel, run from pure Fortran so a failure points at the kernel rather than the bindings.

Checked: translational invariance of the energy, vanishing net force, and agreement between the analytic forces and a central difference of the energy. The finite-difference check is the acceptance gate. Two configurations carry the checks. The diamond lattice at its experimental constant places every bond inside the inner taper radius, where the cutoff function is flat and its derivative drops out; the expanded lattice places bonds in the taper window so the cutoff derivative enters both the pair term and the coordination sum. Both carry a fixed jitter, because a force that vanishes by symmetry tests nothing.

ABI identity. ``RGPOT_ENGINE_ABI_VERSION`` is the major: an incompatible change increments it, and a host compares it for equality. Additions that leave every existing call valid (a new optional symbol, a new field at the end of a size-prefixed struct) increment ``RGPOT_ENGINE_ABI_MINOR``. .. index:: pair: define; RGPOT_PAIR_API

	:class: doxyrest-title-code-block

	#define RGPOT_PAIR_API

Reduced cluster pair kernels used by anneal.

Lennard-Jones is the unshifted Wales and Doye form ``4 epsilon [(sigma/r)^12 - (sigma/r)^6]``, with no cutoff when ``cutoff <= 0``. Morse is the Doye and Wales form ``epsilon exp(rho (1 - r/re)) (exp(rho (1 - r/re)) - 2)``, again unshifted. The unit Lennard-Jones branch (epsilon = 1, sigma = 1, cutoff <= 0) uses the same expression tree as anneal's PairKind::LennardJones so a search sees the same rounding.

Gradients are derivatives of the energy, not physical forces.

.. index:: pair: define; RGPOT_SC_API
.. _doxid-_sutton_chen_pot_8hpp_1a08f293acd959e27bc8eaf06cb67fce4f:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	#define RGPOT_SC_API

Sutton-Chen potential.

Sutton and Chen, Philosophical Magazine Letters 61, 139 (1990):

E = epsilon \* [ 1/2 sum_i sum\_{j != i} (a / r_ij)^n

* c \* sum_i sqrt(rho_i) ] rho_i = sum\_{j != i} (a / r_ij)^m

Gold and platinum use n = 10, m = 8, c = 34.408. The cluster references are in the reduced units epsilon = 1, a = 1 written on the first line of the Doye and Wales point files (doye.chem.ox.ac.uk/jon/structures/SC/10-8/). Those files are the deposited Pt38 Oh and Pt75 D5h geometries. Doye and Wales attribute n, m and c to the 1990 paper. Physical epsilon and a for both metals are the presets in :ref:`SuttonChenScales.hpp <doxid-_sutton_chen_scales_8hpp_source>`.

optbench's globalopt Lennard-Jones problems truncate at cutoff 40 in the coordinate unit (problems/globalopt/lj75.toml). The same truncation, with no energy shift, is the default. cutoff <= 0 keeps every pair. On the deposited clusters every pair sits inside r = 3, so the default and the full sum agree past the published digits.
