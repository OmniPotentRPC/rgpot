	:ref:`CacheRoot<doxid-structrgpot_1_1aoti__unpack_1_1_cache_root>` resolve_cache_root(const std::string& configured)

The cache root, in order: the explicit config value, $RGPOT_CACHE_DIR, $XDG_CACHE_HOME/rgpot (absolute values only, as the XDG base directory specification requires), then .rgpot-cache in the working directory. The result is absolute, so a later chdir does not move it.

.. index:: pair: function; unpack
.. _doxid-aoti__unpack_8hpp_1a6bd8d03b01a01fd20c6b8c0a3140310d:

.. ref-code-block:: cpp

	:ref:`Unpacked<doxid-structrgpot_1_1aoti__unpack_1_1_unpacked>` unpack(const fs::path& package, const fs::path& root, const std::string& model = "model")

Unpack ``package`` under ``root`` and return the unpacked paths. A valid earlier unpack of the same bytes is reused; no file is ever written outside ``root``.
