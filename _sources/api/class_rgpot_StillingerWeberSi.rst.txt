Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Stillinger-Weber silicon with the 1985 published parameters.

One call evaluates a whole configuration. ``energyAndGradientBatch`` evaluates many configurations that share a cell and a species list, so a caller crosses into the library once per batch rather than once per pair.

	virtual uint64_t paramsKey() const

Fingerprint of the potential's parameter set.

Mixed into the result-cache key so results never cross parameter sets. Implementations hash their config field by field (see :ref:`ParamHash.hpp <doxid-_param_hash_8hpp_source>`) plus a kernel-version salt that changes whenever the numerics change. The default (0) suits parameter-free potentials whose numerics never changed.

Energy and dE/dx for one configuration.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- positions

		- Row-major n_atoms by 3 coordinates, Angstrom.

	*
		- atomic_numbers

		- Length n_atoms. Unused: the 1985 set is silicon.

	*
		- box

		- Row-major 3 by 3 cell, Angstrom. Periodic in every direction.

	*
		- n_atoms

		- Atom count.

	*
		- energy

		- Receives the potential energy, eV.

	*
		- gradient

		- Receives dE/dx, length 3 \* n_atoms, eV/Angstrom. The library force is the negation of this gradient.

	*
		- neighbors

		- Optional Verlet list. Null rebuilds the pairs on every call. A list is reused while each atom has moved by at most half its skin and the cell is unchanged.
