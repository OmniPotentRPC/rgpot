Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Where the driver connects, the species it serves, and how the geometry is handed to the evaluation.

address is ``unix:/absolute/path``, ``unix:<name>`` (connects to ``<unix_prefix><name>``, by default ``/tmp/ipi_<name>``), ``tcp:<host>:<port>`` or ``tcp:<port>`` (host 127.0.0.1).
