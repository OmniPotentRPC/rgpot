.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	void forceImpl(const :ref:`ForceInput<doxid-structrgpot_1_1_force_input>`& in, :ref:`ForceOut<doxid-structrgpot_1_1_force_out>`* out) const

Every rank of the calling calculator enters this call together. Positions and the box are Angstrom; the energy is eV and the forces eV/Angstrom. An unconverged SCF throws :ref:`CP2KScfError <doxid-classrgpot_1_1_c_p2_k_scf_error>` on every rank. Any other failure is printed on every rank of the calculator, then MPI_Abort runs on MPI_COMM_WORLD, and then the exception leaves the call.

	void selectOrbitals(int64_t key)

Names the calculation the following forces belong to (a band image, a ring-polymer bead). The shim keeps one CP2K force environment per key, so each keeps its own wavefunction. Every rank of a calculator names the same key before the same force.

	static int bindCalculators(int ranks_per_calc)

Collective on MPI_COMM_WORLD, as :ref:`CPMDPot::bindCalculators <doxid-classrgpot_1_1_c_p_m_d_pot_1adaecbf76c0c5f2fda166136873c07e7b>` : splits into calculators of ranks_per_calc ranks and hands the shim the calculator communicator.
