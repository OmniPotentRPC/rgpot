Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Implementation of a shifted 12-6 Lennard-Jones potential.

Pairwise interactions within the cutoff radius, minimum image convention on an orthogonal or sheared box. Pairs come from the shared neighbour layer: a cell list, a Verlet skin, and either a stored list or a streaming walk. The pair term runs during that walk. A streaming call does not copy a half-list. A stored call keeps candidates out to the cutoff plus the skin and drops the rest from the current distances, so a later call inside half the skin reuses the candidates. Several threads split the atoms, keep a private force buffer, and add those buffers in thread order. A nonzero switch width uses the quintic switch. Cauchy stress is published from the kernel's strain accumulator.

.. warning::

	The box is assumed to be orthogonal.

.. ref-code-block:: cpp

	virtual uint64_t paramsKey() const

Fingerprint of the potential's parameter set.

Mixed into the result-cache key so results never cross parameter sets. Implementations hash their config field by field (see :ref:`ParamHash.hpp <doxid-_param_hash_8hpp_source>`) plus a kernel-version salt that changes whenever the numerics change. The default (0) suits parameter-free potentials whose numerics never changed.
