enum rgpot::nlist::Mode
=======================

Stored keeps a Verlet list of candidate pairs. Stream walks the cells and stores nothing beyond the atoms and the bins. Auto stores when the candidate index array fits in the memory the OS reports as available, and streams otherwise.
