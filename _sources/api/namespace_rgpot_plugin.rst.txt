	std::unique_ptr<:ref:`PotentialBase<doxid-classrgpot_1_1_potential_base>`> create_from_plugin(const :ref:`rgpot_plugin_descriptor_t<doxid-structrgpot__plugin__descriptor__t>`* desc, const std::string& config = "{}")

Create a PotentialBase-compatible wrapper from a loaded plugin. The returned object owns the plugin instance and handles unit conversion.



.. rubric:: Parameters:

.. list-table::
	:widths: 20 80

	*
		- desc

		- Plugin descriptor (must outlive the returned object).

	*
		- config

		- JSON config string passed to desc->create().



.. rubric:: Returns:

A unique_ptr to a :ref:`PotentialBase <doxid-classrgpot_1_1_potential_base>`.
