Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

CP2K input decks from CP2KParams and one geometry.

Pure text functions without libcp2k, so the deck :ref:`CP2KPot <doxid-classrgpot_1_1_c_p2_k_pot>` hands the shim can be tested on its own.
