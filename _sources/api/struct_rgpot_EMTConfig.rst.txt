struct rgpot::EMTConfig
=======================

.. toctree::
	:hidden:

Parameters for the Asap effective-medium potential. ``rasmussen`` selects :ref:`EMTRasmussenParameterProvider <doxid-class_e_m_t_rasmussen_parameter_provider>` (Al, Cu, Ag, Au). The default, ``emt_rasmussen = false``, is the Asap default provider (H, Mg, Al, Ni, Cu, Pd, Ag, Pt, Au).

	};
