Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Minimum-image wrap from the minimage static library.

Fractional rounding. Exact for an orthorhombic cell, and for a skewed cell when the wrapped length sits strictly inside half the smallest face altitude (Smith, CCP5, 1989). Outside that bound the 26-image scan below is the nearest image.
