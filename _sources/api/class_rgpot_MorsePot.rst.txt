Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Pairwise Morse potential, :math:`V(r) = D_e [1 - e^{-a(r - r_e)}]^2 -
D_e`, shifted so that :math:`V(r_\mathrm{cut}) = 0`.

Pairwise interactions within the cutoff radius. The minimum image comes from the shared neighbour layer, on an orthogonal or sheared box. The pair term runs during the cell walk. A stream does not copy a half-list. A stored list keeps candidates out to the cutoff plus a skin of one fifth of the cutoff, and a later call inside half that skin reuses them. The distance filter uses the positions of this call.

With ``:ref:`MorseConfig::switch_width <doxid-structrgpot_1_1_morse_config_1a7fe1ac125cf3568298a35231de30561c>``` set, each pair term is the unshifted Morse energy times the C^2 quintic switch of :ref:`PairSwitch.hpp <doxid-_pair_switch_8hpp_source>`; otherwise the energy is shifted to zero at the cutoff and the force jumps there. The pair term is ``simd::exp_fixed``, so a per-pair accumulation and this row return the same bits. Cauchy stress is the derivative of that energy.

.. warning::

	The box is assumed to be orthogonal.

.. ref-code-block:: cpp

	virtual uint64_t paramsKey() const

Fingerprint of the potential's parameter set.

Mixed into the result-cache key so results never cross parameter sets. Implementations hash their config field by field (see :ref:`ParamHash.hpp <doxid-_param_hash_8hpp_source>`) plus a kernel-version salt that changes whenever the numerics change. The default (0) suits parameter-free potentials whose numerics never changed.
