struct rgpot::nlist::Buffers
============================

.. toctree::
	:hidden:

Caller-owned buffers for one chunk. ``first`` and ``second`` have the same length, which is the maximum number of pairs this pull writes. ``shift`` and ``vector`` are empty or three times that length.
