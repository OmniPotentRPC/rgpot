struct rgpot::nlist::Systems
============================

.. toctree::
	:hidden:

Several systems that do not interact. ``positions`` is the concatenation of every system, ``count`` atoms each. ``box9`` holds nine lattice values per system, in the same order. ``count[s] == 0`` is an empty system.
