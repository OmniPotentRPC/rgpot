class rgpot::CP2KScfError
=========================

.. toctree::
	:hidden:

The SCF did not converge. The shim agrees on this outcome over the calculator's communicator, so every rank of the calculator throws it for the same call and no rank aborts the world. A caller may reject the geometry and continue.
