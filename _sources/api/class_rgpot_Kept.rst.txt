	template <typename Make, typename Run>
	static decltype(auto) with(const :ref:`KeptKey<doxid-classrgpot_1_1_kept_key>`& key, Make&& make, Run&& run)

``run(pot)`` on the potential kept for *key*. When the key differs, the kept potential is dropped and ``make()``, which returns a ``std::unique_ptr<Pot>``, builds the next one. A throw from ``make`` leaves none kept. A throw from ``run`` drops the potential, whose scratch it may have left half written, and passes on.
