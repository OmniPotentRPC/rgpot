Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Embedded-atom aluminium, palladium and gold.

The neighbour search is a linked-cell list with a Verlet skin. The force loop visits the same pairs, in the same atom order, as the direct double loop, and the arithmetic of each pair is unchanged. ``OMP_NUM_THREADS`` above 1 splits atoms across threads. The variable is read on each call. When it is unset the call stays on one thread.
