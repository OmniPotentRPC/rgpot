Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Owning table. The arrays are the storage a caller can wrap without copying. ``device`` is 0 for host memory. A GPU fill would use the same layout and a non-zero device id; this build fills host memory.
