	double n[3]

Convert derivative to force. Vector *n* is by definition the vector which satisfy the equation:

.. math::

	\mathbf{F}=-\frac{dE}{d\rho}\mathbf{n}

It is equal to:

.. math::

	\mathbf n=\frac{\mathbf{r}}{|\mathbf{r}|}\frac{r_e}{\rho^2}
