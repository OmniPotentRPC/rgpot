class rgpot::nlist::Builder
===========================

.. toctree::
	:hidden:

Stored list with a skin rebuild. A later update keeps the table while every atom has moved by at most half the skin and the cell and the query are unchanged. Skin 0 rebuilds unless the coordinates match. Throws :ref:`Error <doxid-classrgpot_1_1nlist_1_1_error>` and keeps the previous table when the geometry is rejected. The same builder is used by one thread. Two builders may update at the same time.
