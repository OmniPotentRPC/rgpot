Global Variables

.. index:: pair: variable; kCxxLayoutRevision
.. _doxid-_cxx_layout_8hpp_1ac7b4d4e345fba7e766ff7bd887f854b5:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	std::uint32_t kCxxLayoutRevision = 1

Hand-maintained. Increment when a change the hash cannot see alters the C++ ABI: reordering virtuals without changing their count, changing the meaning of a field, changing a base class of a covered type. Any change to size, alignment or a field offset moves the hash by itself.

.. index:: pair: variable; kPotentialBaseVirtuals
.. _doxid-_cxx_layout_8hpp_1a658bcb7d732752d499f279c25b1008a5:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	std::uint32_t kPotentialBaseVirtuals = 5

Virtual functions declared by ``:ref:`PotentialBase <doxid-classrgpot_1_1_potential_base>```, destructor included. The cache hook ``set_cache`` adds one when ``RGPOT_HAS_CACHE`` is defined. A test counts the ``virtual`` declarations in Potential.hpp and fails when this and the header disagree.
