Detailed Documentation
~~~~~~~~~~~~~~~~~~~~~~

Private per-atom arrays, one per slice, for a walk that writes both atoms of a pair from any slice.

Slice ``t`` tallies into ``slot(t)``; ``reduce`` adds the slots into the caller's arrays in slice order. A null target allocates nothing and hands out empty slots.
