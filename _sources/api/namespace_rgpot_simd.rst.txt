	const char* chosen_target_name()

	void set_target_for_test(const char* name)

Test hook. "scalar" forces the portable kernel. A known target the CPU cannot run falls back to the best target it can run. On x86-64 that is at least SSE2. An unknown name is ignored. Not for production paths: Highway's chosen target is process-wide.

	double exact_fma(double a, double b, double c)

a\*b+c with one rounding, the same bits as a hardware fused multiply-add. Normals in range use a Dekker product and a round-to-odd sum (Boldo and Melquiond). Inputs outside that range and subnormal results use std::fma.

.. index:: pair: function; exp
.. _doxid-exp_8cc_1a4021c088b81552fe0d7a8a82acc684d3:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	double exp(double x)

Scalar exp. Cody-Waite reduction by a split ln(2), then the fdlibm degree-5 polynomial. The large-argument scale and each polynomial product-sum are one rounding. Overflow returns +inf, underflow returns 0, a NaN returns a NaN, and exp(-0) is +1. Vector targets replay these operations per lane.

.. index:: pair: function; exp_fixed

	double exp_fixed(double x)

e^x with the same bits on every instruction set and C library. Within 1.24 ulp for normal results (see docs/orgmode/reference/simd_exp.org).

.. index:: pair: function; fill_view
.. _doxid-from__cache_8hpp_1a4447ac3a4a74a41252d0fabec6219cda:

.. ref-code-block:: cpp
	:class: doxyrest-title-code-block

	void fill_view(:ref:`CachedPairs<doxid-structrgpot_1_1simd_1_1_cached_pairs>`& out, const double* R, std::size_t n, const double* box, const :ref:`PairSpec<doxid-structrgpot_1_1simd_1_1_pair_spec>`& opt, nlist::Mode mode = nlist::Mode::Auto, :ref:`nlist::Neighbours<doxid-classrgpot_1_1nlist_1_1_neighbours>`* reuse = nullptr)

Build a half-list for the dispatched pair kernels. Candidates come from the shared neighbour layer. ``reuse`` keeps the Verlet list across calls. Several threads walk disjoint atoms and the rows are sorted, so the list does not depend on which thread found a pair. fold is the orthorhombic round, with a zero inverse on an axis the options leave unfolded.
