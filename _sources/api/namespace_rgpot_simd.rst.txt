	double exact_fma(double a, double b, double c)

a\*b+c with one rounding, the same bits as a hardware fused multiply-add. Normals in range use a Dekker product and a correctly rounded sum of the three exact parts. Zeros, subnormals, overflows, and non-finite values use std::fma.

	double mul_add(double a, double b, double c)

a\*b+c, one rounding. A hardware instruction when this translation unit has one, or when glibc reports FMA usable. Otherwise fma_quick.
