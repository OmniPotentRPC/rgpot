=========================
Contributing to ``rgpot``
=========================


We welcome all contributions and contributors to ``rgpot``.
Whether you report bugs, improve documentation, or submit code, your help makes
the tools better for everyone.

Communication and Conduct
-------------------------

We value a respectful and inclusive community.
All contributors must follow our
:doc:`Code of Conduct <../code_of_conduct>`.

Getting Started
---------------

Please review the technical requirements before submitting a Pull Request:

Development Environment
    We use ``pixi`` for environment management.

See the :doc:`Developer Guide <developer/index>` for setup and common
tasks.

Documentation
    We author all documentation in ``orgmode`` converted to ``rst``.

See :doc:`Developer FAQ <developer/faq>` for documentation workflow
details.

Reporting Issues
----------------

Ask questions, report bugs and suggest enhancements on the
`rgpot issue tracker <https://github.com/OmniPotentRPC/rgpot/issues>`_.
Please provide a minimal reproducible example for all bug reports.
Report security vulnerabilities privately, following
`SECURITY.md <https://github.com/OmniPotentRPC/rgpot/blob/main/SECURITY.md>`_.
Do not open a public issue for them.
